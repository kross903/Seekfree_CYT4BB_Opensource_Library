# RotorPy PID 仿真真实化改进指南

当前仿真用于验证控制链路方向、PID 参数影响和闭环趋势，不等价于实机。后续要让仿真更接近实际，应按下面顺序推进。

## 1. 机体参数

- 实测整机质量，并替换 RotorPy 车辆参数中的 `mass`。
- 测量电机到机体中心的轴距，替换 `rotor_pos`。
- 估算或测量转动惯量 `J`，优先保证 roll/pitch 轴惯量接近实机。
- 确认电机编号、旋向和混控矩阵与 `motor_mixer.c` 一致。

## 2. 电机与油门模型

- 用拉力计标定油门到推力曲线，不要长期使用线性油门到转速映射。
- 标定不同电池电压下的推力变化，建立电压补偿或电压下垂模型。
- 加入电机一阶响应延迟，模拟电调和桨叶转速建立过程。
- 检查最小起转油门和实际有效油门上限，避免仿真中出现实机做不到的推力。

## 3. 传感器模型

- 用 VOFA 静止数据估计陀螺仪和加速度计噪声，加入 IMU 噪声和零偏漂移。
- 按实际 ToF 更新频率、延迟、噪声、离群点和安装角补偿建模。
- 按实际光流更新频率、旋转补偿残差、丢帧、尖峰和速度低通建模。
- 位置观测应支持视觉/红外定位的低频、延迟、噪声和偶发丢失。

## 4. 环境与气动

- 初期保持 `aero=False`，先调通 PID 主链路。
- 控制链路稳定后，再逐步打开 RotorPy 气动项和风场。
- 地面附近应加入地效或起飞阶段推力变化，否则高度环起飞仿真会过于理想。
- 风场先用于动画箭头可视化，确认模型后再让风实际影响动力学。

## 5. 频率与延迟

- 仿真中的姿态环、角速度环、高度环、位置环频率应和固件实际中断/任务频率一致。
- 对低频传感器不要每个控制步都刷新，应保持采样保持逻辑。
- 加入执行器延迟、传感器延迟和滤波延迟，重点观察速度环和高度环相位裕度。

## 6. 与实测数据对齐

- 选取一次 VOFA 飞行 CSV，包含高度、速度、角度、角速度、电机输出。
- 在仿真中使用相同目标输入和初始条件。
- 对比上升段、高度稳态、位置收敛、roll/pitch 响应、电机输出幅值。
- 优先让响应时间、超调、稳态误差和输出限幅趋势对齐，而不是只看最终位置。
