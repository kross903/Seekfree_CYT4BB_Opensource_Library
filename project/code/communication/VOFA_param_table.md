### 1.8 光流速度环 PID

这组参数用于光流速度闭环。PID 输出不是角度，而是水平加速度指令，单位为 `cm/s^2`；控制代码再将其换算为 `pitch_corr_deg / roll_corr_deg`。

| 参数 | X 方向默认值 | Y 方向默认值 |
|---|---:|---:|
| `Kp` | `1.70` | `1.70` |
| `Ki` | `0.00` | `0.00` |
| `Kd` | `0.00` | `0.00` |
| 输出限幅 `output_limit` | `85.0 cm/s^2` | `85.0 cm/s^2` |
| 积分限幅 `integral_limit` | `20.0` | `20.0` |

### 1.9 红外位置环 PID

这组参数用于把红外正方形中心坐标闭环到 `(0, 0)`。中心坐标已支持三点补全并经过 Kalman 滤波；位置环输出目标速度，再交给现有光流速度环；起飞 ramp 完成进入巡航分支后自动接入，也可通过 `I0=1!` 或 `J0=1!` 手动开启。

### 2.3 悬停基准角补偿

当前起飞采样基准为 `0deg / 0deg`，下面两个补偿量会叠加到 `Flight_Takeoff_Get_Captured_Angles()` 的返回值，并作为速度环叠加前的悬停姿态基准。内部限幅为 `±10deg`。

| 参数 | 默认值 | VOFA 指令 |
|---|---:|---|
| Roll 悬停基准角补偿 | `-2.1` | `B1=<value>!` |
| Pitch 悬停基准角补偿 | `0.65` | `B2=<value>!` |

| `PMW_FLOW_VEL_Y_LPF_ALPHA` | `0.18` | Y 方向光流速度反馈低通，抑制 Roll 目标角抖动 |

## 5. VOFA 回传模式切换指令

| 指令 | 含义 |
|---|---|
| `F0!` | 默认飞行状态回传 |
| `F1!` | PID 参数回读 |
| `F2!` | 定位 / 高度观察 |
| `F3!` | 链路测试 |
| `F4!` | 陀螺仪调试 |
| `F5!` | 加速度调试 |
| `F6!` | Roll/Pitch 角度与角速度对比 |
| `F7!` | ADC 原始值、滤波值与目标角 |
| `F8!` | 光流速度闭环综合监视 |
| `F9!` | 加速度积分速度与光流速度对比 |
| `FA!` | 加速度水平化残差诊断 |
| `FB!` | 光流速度旋转到世界系后的速度与积分位置 |
| `FC!` | 速度积分位置与光流单帧位移积分位置对比 |
| `FD!` | 高度环全要素监视 |
| `FE!` | 光流原始输入诊断 |
| `FF!` | Roll/Pitch 角度环监视 |
| `FG!` | 红外正方形中心点与丢失保护诊断 |
| `FH!` | 红外丢失保护状态机诊断 |
| `FI!` | 红外位置闭环诊断 |
| `FJ!` | 速度环/光流门控诊断 |

## 7. 说明

- 本表列的是当前工程源码中的默认值，不代表你板子运行时一定还是这些值。
- 如果启用了菜单调参、VOFA 调参或 Flash 参数存储，运行时值可能已经被改写。
- 当前 VOFA 指令并没有开放所有限幅参数；有些限幅虽然代码里有默认值，但暂时不能直接通过 VOFA 单独调。
