# 小车运动前馈上行协议

## 协议约束

- 协议 ID：`0x15`。
- 协议版本：`3`。
- 载荷长度：固定 22 字节。
- 发送周期：小车每 20 ms 发送一次；无人机每 4 ms 重建一次当前运动状态。
- 两端必须同步烧录；V3 不兼容 V2、旧版 `0x13` 或早期 40 字节 `0x15`。
- 无人机遇到版本、长度、非法标志组合、乱序时间或越界向量时整包拒绝，不刷新数据年龄。

## 载荷布局

| 偏移 | 字段 | 格式与单位 |
| ---: | --- | --- |
| 0 | `version` | `uint8`，固定为 3 |
| 1 | `flags` | `uint8` |
| 2 | `sequence` | `uint16` 小端，自然回绕 |
| 4 | `sample_time_ms` | `uint32` 小端，小车单调毫秒时间，自然回绕 |
| 8 | `car_absolute_yaw_ddeg` | `int16` 小端，0.1 deg |
| 10 | `actual_world_vx_dcms` | `int16` 小端，0.1 cm/s |
| 12 | `actual_world_vy_dcms` | `int16` 小端，0.1 cm/s |
| 14 | `planned_world_ax_cms2` | `int16` 小端，cm/s² |
| 16 | `planned_world_ay_cms2` | `int16` 小端，cm/s² |
| 18 | `planned_world_jx_cms3` | `int16` 小端，cm/s³ |
| 20 | `planned_world_jy_cms3` | `int16` 小端，cm/s³ |

`flags` 定义：

- bit0 `VELOCITY_VALID`：世界系实际速度有效。
- bit1 `ACCEL_VALID`：世界系计划加速度有效；置位时 bit0 必须同时置位。
- bit2 `JERK_VALID`：世界系计划 Jerk 有效；置位时 bit1 必须同时置位。
- bit3 `SEARCH_REQUEST`：小车处于非遥控的自动信标导航且当前无目标，请求无人机搜索。
- bit4 `YAW_VALID`：小车绝对 Yaw 有效，独立于速度有效位。
- bit5 `TRAJECTORY_RESET`：整形状态发生初始化或不连续，本包 Jerk 不用于跨段连续性推断。
- bit6～bit7 必须为 0。

## 数据语义与坐标规则

- `V_actual` 来自小车里程计/EKF的实际世界速度。
- `A_plan` 来自小车平移速度整形器当前输出的世界系计划加速度。
- `J_plan` 由相邻两个 5 ms 计划加速度样本差分得到，并按小车配置的二维 Jerk 上限约束。
- X/Y 使用小车与无人机已对齐零点和正方向的共享世界系。无人机禁止再用小车 Yaw 或当前 Yaw 旋转 V/A/J。
- Yaw 仍同步，用于搜索、视觉链路、诊断和备用信息，不作为世界系前馈成立的前提。
- 实际速度进入位置环速度前馈，并用于相对小车运动计算；计划加速度允许启动和制动分量进入速度环加速度前馈。
- 小车遥控模式仍发送有效的V/A/J前馈；遥控模式只清除`SEARCH_REQUEST`，不会关闭运动前馈。
- 速度前馈使用 M1/M2 增益，加速度前馈使用独立的 M6/M7 增益。
- A/J安全速度模型只限制位置纠偏分量，不削弱小车实际速度前馈。

## 无人机时间重建

无人机依据采样时间、包到达时间和收包后的本地经过时间，在每个 4 ms 控制周期计算：

```text
A(t) = A0 + J0 × dt
V(t) = Vactual0 + A0 × dt + 0.5 × J0 × dt²
```

- 两端不要求绝对时钟相同。无人机估计“小车时间→无人机时间”的偏移；观察到更小偏移时立即跟随，观察到更大偏移时缓慢跟随，避免把链路抖动误判成时钟漂移。
- 固定单向链路延迟先按3 ms补偿；`uint32`时间差使用模运算，支持约49.7天自然回绕。
- 预测时域最多60 ms。收包后60～100 ms内保持60 ms预测终点并将V/A前馈线性撤销到0；超过100 ms失效。
- Jerk无效时按0处理；加速度无效时A/J均按0处理。
- 无人机整包接收时检查二维速度、加速度和Jerk上限，重建后再次进行二维模长限幅，作为异常包的最后保护。

## 控制与失效规则

以下任一条件成立时，对应前馈不参与控制：

- 最近合法包的本地年龄超过100 ms。
- 对应有效标志为0。
- 向量数据越界或非有限。
- 位置环关闭、融合速度反馈无效，或位置观测及短时预测均不可用。

`0x14`仍用于无人机向小车发送信标观测；地图、信标ID/位置和导航目标不再由小车回传给无人机。无人机只在`SEARCH_REQUEST=1`时累计无目标时间，请求撤销或链路超时会退出搜索并锁定当前Yaw。
