# 小车运动前馈上行协议

## 协议约束

- 协议 ID：`0x15`。
- 协议版本：`4`。
- 载荷长度：固定 18 字节。
- 发送周期：小车每 20 ms 发送一次；无人机每 4 ms 更新一次前馈状态。
- 两端必须同步烧录；V4 不兼容 V3、旧版 `0x13` 或早期 40 字节 `0x15`。
- 无人机遇到版本、长度、非法标志组合、乱序时间或越界向量时整包拒绝，且不刷新本地收包年龄。

## 载荷布局

| 偏移 | 字段 | 格式与单位 |
| ---: | --- | --- |
| 0 | `version` | `uint8`，固定为 4 |
| 1 | `flags` | `uint8` |
| 2 | `sequence` | `uint16` 小端，自然回绕 |
| 4 | `sample_time_ms` | `uint32` 小端，小车单调毫秒时间，自然回绕 |
| 8 | `car_absolute_yaw_ddeg` | `int16` 小端，0.1 deg |
| 10 | `planned_world_vx_dcms` | `int16` 小端，0.1 cm/s |
| 12 | `planned_world_vy_dcms` | `int16` 小端，0.1 cm/s |
| 14 | `planned_world_ax_cms2` | `int16` 小端，cm/s² |
| 16 | `planned_world_ay_cms2` | `int16` 小端，cm/s² |

`flags` 定义：

- bit0 `VELOCITY_VALID`：世界系计划速度有效。
- bit1 `ACCEL_VALID`：世界系计划加速度有效；置位时 bit0 必须同时置位。
- bit2 `SEARCH_REQUEST`：活动的自动信标导航允许无人机自搜索；实际起转由无人机视觉丢失状态机决定。
- bit3 `YAW_VALID`：小车绝对 Yaw 有效，独立于速度有效位。
- bit4～bit7 必须为 0。

## 数据语义与坐标规则

- `V_plan`和`A_plan`均来自小车平移速度整形器的当前世界系输出，不再发送里程计/EKF实际速度，也不再发送Jerk。
- X/Y 使用小车与无人机已对齐零点和正方向的共享世界系。无人机禁止再按小车 Yaw 或当前 Yaw 旋转 V/A。
- Yaw 仍用于搜索、视觉链路和诊断，不作为世界系前馈成立的前提。
- 小车遥控模式仍运行平移整形器并发送有效V/A；遥控模式清除`SEARCH_REQUEST`，活动的自动信标导航持续置位。
- 计划速度通过 M1/M2 增益进入位置环速度前馈，计划加速度通过独立的 M6/M7 增益进入速度环加速度前馈。
- A/J安全速度模型只限制位置纠偏分量，不削弱小车计划速度和计划加速度前馈。

## 无人机保持和平滑

无人机不再通过Jerk预测未来状态。每个4 ms周期执行：

1. 最新合法包年龄不超过80 ms时，以最新`V_plan`和`A_plan`为目标。
2. 速度采用二维模长变化率限制追踪目标，变化率固定为`200 cm/s²`；4 ms内最大二维速度变化为`0.8 cm/s`。
3. 加速度采用10 Hz一阶低通，4 ms周期对应系数约`0.201`。
4. 速度平滑后再应用M1/M2；加速度低通后再应用M6/M7，M6/M7上电默认值为0.4。

二维速度限制针对`目标向量-当前向量`的模长，不能分别限制X/Y，否则对角线方向的总变化率会超过200 cm/s²。

## 时效与失效规则

- `0～80 ms`：`FRESH`，继续使用最新计划速度和计划加速度。
- `>80～130 ms`：`STALE`，速度平滑目标和加速度低通目标都改为0。
- `>130 ms`：`INVALID`，链路标记无效，但已平滑的V/A状态仍按相同规则连续回零，禁止突变清零。
- 新合法包恢复后，V仍以`200 cm/s²`追向新值，A仍经10 Hz低通恢复，不产生单周期跳变。

`sequence`用于识别新包、重复包和乱序包；无人机本地单调时间用于计算包年龄和相邻合法包到达间隔。`sample_time_ms`仅用于检查小车采样时间是否前进以及诊断发送周期，不再参与单向延迟预测。重复或乱序包不能刷新接收年龄。

以下任一条件成立时，对应原始数据不再作为新的平滑目标：

- 最近合法包年龄超过80 ms。
- 对应有效标志为0。
- 向量越界或协议字段非法。

位置环关闭或融合速度反馈无效时，位置环会停止采用前馈。视觉位置是否有效只决定位置纠偏分量，不应撤销仍处于`FRESH`状态的小车V/A前馈。

`0x14`仍用于无人机向小车发送信标观测；地图、信标ID/位置和导航目标不再由小车回传给无人机。无人机只在`SEARCH_REQUEST=1`且链路未失效时累计视觉丢失时间；可信视觉会清零计时，许可撤销或链路超时会退出搜索并锁定当前Yaw。水平速度连续稳定150 ms且视觉连续丢失300 ms后才允许起转。默认搜索速度为`60 deg/s`；每次解锁后首次搜索到达相对起始Yaw的第一个90度端点后持续等待可信信标，首次找到过信标后，后续丢灯搜索在`+/-90 deg`端点间往返，每个端点停留`300 ms`。
