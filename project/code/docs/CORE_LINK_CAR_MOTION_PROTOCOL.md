# 小车运动前馈上行协议

## 协议约束

- 协议 ID：`0x15`。
- 协议版本：`2`。
- 载荷长度：固定 14 字节。
- 发送周期：小车每 20 ms 发送一次。
- 两端必须同步烧录；不兼容旧版 `0x13` 或 40 字节 `0x15`。
- 无人机遇到版本、长度或标志位错误时整包拒绝，不刷新数据年龄。

## 载荷布局

| 偏移 | 字段 | 格式与单位 |
| ---: | --- | --- |
| 0 | `version` | `uint8`，固定为 2 |
| 1 | `flags` | `uint8` |
| 2 | `sequence` | `uint16` 小端，自然回绕 |
| 4 | `car_absolute_yaw_ddeg` | `int16` 小端，0.1 deg |
| 6 | `actual_forward_speed_dcms` | `int16` 小端，0.1 cm/s |
| 8 | `actual_left_speed_dcms` | `int16` 小端，0.1 cm/s |
| 10 | `planned_forward_acc_cms2` | `int16` 小端，cm/s2 |
| 12 | `planned_left_acc_cms2` | `int16` 小端，cm/s2 |

`flags` 定义：

- bit0 `MOTION_VALID`：Yaw 和实际速度有效。
- bit1 `PLAN_ACCEL_VALID`：小车整形后的计划加速度有效。
- bit2 `SEARCH_REQUEST`：小车处于非遥控的自动信标导航且当前无目标，请求无人机搜索。
- bit3～bit7 必须为 0。

## 坐标与使用规则

- 速度和加速度均采用小车车体系：X 向前，Y 向左。
- 小车和无人机 Yaw 必须使用相同零点和正方向。
- 无人机先用 `car_yaw-uav_yaw` 将两个向量旋转到无人机机体系，再转到地理系。
- 实际速度进入位置环速度前馈，并用于计算无人机相对小车的径向接近速度。
- 计划加速度同时允许启动和制动分量进入速度环加速度前馈。
- 速度与加速度共用 M1/M2 前馈增益，不增加独立参数。
- 无人机只在`SEARCH_REQUEST=1`时累计无目标时间；请求撤销或链路超时会立即退出搜索并锁定当前Yaw。

## 失效规则

以下任一条件成立时，对应前馈不参与控制：

- 合法包年龄超过 200 ms。
- 对应有效标志为 0。
- 小车 Yaw、无人机 Yaw或向量数据无效。
- 位置环关闭、融合速度反馈无效或位置观测及短时预测均不可用。

`0x14` 仍用于无人机向小车发送信标观测；地图、信标 ID/位置和导航目标不再由小车回传给无人机。
