# 小车速度上行协议

## 协议约束

- 协议ID：`0x13`。
- 载荷长度：固定43字节。
- 发送周期：小车每20 ms发送一次。
- 两端必须同步烧录，不兼容旧37字节载荷。
- 无人机只接受长度恰好为43的包；长度错误时整包拒绝，不刷新地图、Yaw、链路年龄或速度状态。

## 载荷布局

前37字节保留小车位置、绝对Yaw和5个信标字段，新增字段如下：

| 偏移 | 字段 | 格式与单位 |
| ---: | --- | --- |
| 37 | `motion_flags` | `uint8` |
| 38 | `motion_sequence` | `uint8` |
| 39 | `car_forward_speed_dcms` | `int16`小端，0.1 cm/s |
| 41 | `car_left_speed_dcms` | `int16`小端，0.1 cm/s |

`motion_flags`定义：

- bit0：融合里程计速度有效。
- bit1：小车存在打滑嫌疑，仅供诊断。
- bit2：小车当前已建立导航目标。

`motion_sequence`每次发送递增，允许8位自然回绕。`car_visible`只表示视觉位置是否有效，不控制速度有效位。

## 坐标约定

- `car_forward_speed_dcms`：小车车体系向前为正。
- `car_left_speed_dcms`：小车车体系向左为正。
- 小车和无人机Yaw必须使用相同零点和正方向。
- 无人机通过`car_yaw-uav_yaw`将小车速度旋转到无人机机体系。

## 失效规则

以下任一条件成立时，无人机不使用小车速度前馈：

- 合法包年龄超过200 ms。
- `motion_flags bit0=0`。
- 小车速度、小车Yaw或无人机Yaw无效。
- 无人机位置环关闭或融合速度反馈无效。

前馈失效时，位置反馈仍可继续工作；前馈经5 Hz低通和最终目标速度变化率限制平滑回零。
