# 电调故障遥测协议

## 串口帧

飞控与四合一电调使用 UART 460800、8N1。帧长固定为 11 字节，校验为前 10 字节的 `uint8` 累加和。

| 字节 | 电调状态帧 `0x07` |
| --- | --- |
| 0 | `0xA5` |
| 1 | `0x07` |
| 2 | 协议版本，当前为 `1` |
| 3 | 故障事件序号 `SEQ` |
| 4 | 本帧事件故障码 `CODE` |
| 5 | 电机掩码，bit0～bit3 对应 M1～M4 |
| 6～9 | M1～M4 当前活动故障码 |
| 10 | 前 10 字节累加校验 |

故障事件连续发送两次，飞控按 `SEQ` 去重。无待发事件时，电调每 100ms 发送 `CODE=0` 的心跳。

## 故障码

| 码 | 含义 | Flight View示例 |
| ---: | --- | --- |
| 1 | 电压异常 | `ESC BOARD VOLTAGE` |
| 2 | 堵转 | `ESC M1 LOCKED` |
| 3 | 干扰保护 | `ESC M2 DISTURB` |
| 4 | 启动失败 | `ESC M3 START FAIL` |
| 5 | 温度过低 | `ESC BOARD TEMP LOW` |
| 6 | 温度过高 | `ESC BOARD TEMP HIGH` |
| 7 | 母线过流 | `ESC BOARD OVERCURRENT` |
| 8 | 低速退出闭环 | `ESC M4 LOW SPEED` |

## 飞控行为

- 飞行、电机测试或飞行测试正在输出时，收到新故障事件会在下一个 4kHz 控制周期触发急停。
- 急停原因锁存为首个电调故障，后续事件不会覆盖屏幕上的根因。
- 电调急停后 2 秒内禁止重新起飞；活动故障未清除时继续拒绝解锁。
- 首个状态帧只同步旧事件序号；若其中仍有活动故障，则按当前故障处理。
- 状态帧超过 500ms 未更新时标记 `STALE`，但第一阶段不因此急停或拒绝解锁。

Flight View的`I/E`依次表示IMU和电调：`OK/OK`正常、`OK/ST`遥测超时、`OK/FLT`存在活动故障、`OK/--`尚未收到状态帧。
