# 飞控滤波链路优化 TODO

## 1. 总体目标

本任务用于逐步建立飞控滤波链路的可观测性，并依据实机数据优化 IMU、姿态控制、高度与光流估计。固定执行顺序为：

```text
建立诊断基线
→ ICM42688 寄存器读回
→ RAM 高速采样
→ 电脑离线 FFT
→ 判断机械/PID/高频振动
→ 有证据才增加 Notch 或修改 AAF
→ 最后优化高度与光流滤波
```

禁止在没有频谱证据时直接降低所有截止频率、启用 Notch 或修改 ICM42688 裸寄存器。

## 6. 阶段四：实机诊断

- [ ] 拆桨静止采集电子噪声基线。
- [ ] 拆桨分别在 300、450、600、750 输出采集。
- [ ] 检查电机、桨叶、轴承、安装螺丝和 IMU 固定。
- [ ] 完成机械检查后进行限高低空悬停采集。
- [ ] 同步使用 F5/F7 观察 P/I/D 和电机差动，区分机械振动与闭环振荡。

判据：

- `5～30 Hz` 且目标、反馈、PID 输出共同摆动：优先调整 PID。
- 固定频率、重复测试位置变化小：候选静态 Notch。
- 随油门大范围移动：不使用单个静态 Notch，后续考虑 RPM 动态 Notch。
- 只存在于原始陀螺、经过 120 Hz 低通后已很小：不增加 Notch。
- 机械异常存在：先修机械，不用滤波掩盖。
