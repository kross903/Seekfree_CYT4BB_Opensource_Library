# IMU 姿态解算与安装矩阵标定

## 1. 使用范围

安装矩阵描述 ICM42688 传感器坐标系到机体坐标系的固定旋转。它不同于起飞目标角，也不同于上电时依据重力方向完成的 Roll/Pitch 初始化。只有飞控板、IMU 或机架安装关系改变时才需要重新标定。

## 2. 安全准备

1. 拆除全部桨叶。
2. 固定摄像头、电池和飞控板，避免标定期间结构移动。
3. 上电预热约 1 分钟。
4. VOFA 使用 JustFloat，发送 `FC!`。
5. `I0/I1/I2` 是安装矩阵处理前的加速度原始计数，脚本使用这三列求解矩阵。
6. `I11` 是基本静止标志，脚本会自动剔除 `I11` 不在 0.5-1.5 范围内的数据。

## 3. 六面采集

依次让机体的 `+X、-X、+Y、-Y、+Z、-Z` 方向竖直朝上。每个姿态保持静止 5-10 秒，分别导出：

```text
px.csv  nx.csv  py.csv  ny.csv  pz.csv  nz.csv
```

每个姿态连续记录 5-10 秒并单独导出 CSV。开始和结束时允许搬动飞机，但每份 CSV 经 `I11` 过滤后必须至少保留 50 行有效静止数据。脚本会按相邻原始重力方向自动分段，并选取文件中最后一个不少于 50 行的连续静止数据块，避免 VOFA 历史缓存中的上一姿态污染结果。六份文件的姿态名称由操作者确认，飞控不会使用尚未标定的矩阵自动判断当前是哪一面。

## 4. 计算矩阵

在库根目录执行：

```powershell
py project\tools\imu_install_calibration.py `
  --px px.csv --nx nx.csv `
  --py py.csv --ny ny.csv `
  --pz pz.csv --nz nz.csv
```

脚本默认读取列名 `I0 I1 I2`，并自动使用 `I11` 过滤非静止行。如果 VOFA 导出的列名不同，使用：

```powershell
--columns 实际X列 实际Y列 实际Z列
```

如果数据表没有静止标志列，可以把 `--valid-column` 指向一个不存在的列名，从而关闭自动过滤：

```powershell
--valid-column NONE
```

脚本输出原始零偏、正交旋转矩阵、等效欧拉角、六姿态最大残差和 `det(R)`。

## 5. 写入与验证

将输出矩阵替换 `icm42688.c` 中的 `k_icm42688_sensor_to_body`，不要手工交换行列。

重新烧录后再次采集六面数据，检查：

- 主重力轴接近 `+1000 mg` 或 `-1000 mg`。
- 另外两轴接近 0。
- `det(R)` 接近 1。
- 脚本最大姿态残差建议小于 1 度。
- 分别绕机体 X/Y/Z 旋转时，处理后的对应陀螺轴为主要变化轴，符号符合机体系定义。

上电姿态初始化不会写入安装矩阵或 Flash，不会覆盖本标定结果。

## 7. 上电姿态初始化与 Flight View

ICM 初始化完成滤波器预热后，会使用当前滤波后的重力方向自动计算初始 Roll/Pitch 四元数。该过程不由 Flight View 按键触发，也不会重新学习陀螺仪零偏；陀螺仪零偏继续使用 Flash 中已有的标定值，除非显式执行陀螺仪标定。

进入 Flight View 后：

- IMU 与 ToF 正常时，按一次 K3 执行安全检查并尝试解锁；角度模式随后进入分阶段缓启动。
- IMU 异常时显示 `IMU: BAD` 和 `IMU FAULT - CHECK F4`，K3 会被安全检查拒绝。
- ToF 最近收到的一个 `2～200 cm` 测距帧有效即可允许起飞；超过 100 ms 没有新帧才判定失效，避免把正常帧间隔误判为故障。缓启动任一阶段发生真正失联都会立即中止启动。
- 飞机解锁后，任意按键仍执行急停。
- 按键急停后进入 2 秒重新解锁禁止期，期间 Flight View 显示 `ESTOP LOCK - WAIT 2S`，KEY3 不会清除急停锁存或重新起飞。

因此 Flight View 不再包含三秒静止采集、标定百分比或二次 K3 确认。六面安装矩阵标定仍通过 VOFA `FC` 命令独立完成。

角度模式缓启动依次显示 `ARM DELAY`、`MOTOR SPIN`、`IDLE HOLD`、`LIFTOFF` 和 `HEIGHT BLEND`。前三个阶段四电机等值输出且不运行姿态 PID；高度 PID 在前四个阶段保持关闭，只在 `HEIGHT BLEND` 阶段从零平滑接管。

如果 KEY3 没有进入缓启动，或启动阶段被其它安全路径中止，Flight View 会锁存 `STOP` 诊断，并显示 `REASON/FILE/LINE/STATE`。下一次 KEY3 请求会清除旧诊断并记录本次结果；完整走完 `HEIGHT BLEND` 后诊断自动清除。

## 8. 视觉 Yaw 启用

视觉 Yaw 融合代码默认关闭。完成地面方向测试后，在 `All_Init.c` 中配置：

```c
#define VISION_YAW_FUSION_ENABLE           (1U)
#define VISION_MARKER_WORLD_HEADING_DEG    (标志在世界坐标中的方向)
#define VISION_CAMERA_YAW_OFFSET_DEG       (摄像头相对机体 X 轴的绕 Z 偏角)
```

启用前应手持旋转飞机，确认视觉航向残差会推动 `current_yaw` 向正确方向缓慢变化。若方向相反，应检查标志世界朝向、摄像头偏角和 `heading_deg` 的正方向，不要直接提高融合增益。
