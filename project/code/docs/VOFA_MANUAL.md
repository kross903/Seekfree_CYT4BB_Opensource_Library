## 连接与命令格式

| 项目 | 当前配置 |
| --- | --- |
| 串口 | UART1 |
| 波特率 | 115200 |
| 数据协议 | VOFA+ JustFloat |
| 帧尾 | `00 00 80 7F` |
| 波形通道 | 8 路或 16 路 float |
| 命令结束符 | `!` |

所有命令必须以 `!` 结尾，例如：

```text
F6!
R1=2.5!
00!
```

拨码 `P09_0` 和 `P09_1` 同时为低电平时，UART1 被切换到逐飞助手图像模式，此时 VOFA 收发停止。调参时应保证没有同时进入图像模式。

发送某个 `F` 指令后，固件会持续发送该模式，直到收到另一个有效的 `F` 指令。通道编号按 VOFA 中的 `I0`、`I1`……排列。

## F2：全局飞行总览

用途：起飞和综合联调时统一观察姿态、高度、速度与位置。该页面用于快速判断问题属于哪一层，不适合代替各闭环专用页面做精调。

本工程坐标约定：

- `F2`中的平移速度与位置误差使用水平惯性坐标系；机头朝初始零航向时，正X向前、正Y向左。
- 光流原始诊断中的 `VX/VY` 仍表示机体系前向/左向；融合器使用光流积分窗口中点Yaw将其转换到惯性系，位置环和速度环直接使用惯性系融合速度。
- 旋转角速度按姿态轴命名：Roll 为横滚轴，Pitch 为俯仰轴，Yaw 为偏航轴。
- 惯性系目标加速度会按当前Yaw转回机体系；仅在Yaw接近零方向时近似为`X → Pitch`、`Y → Roll`。

注意：平移速度的 `VX/VY` 与旋转角速度的 Roll/Pitch 不是同一组轴名称。F2 的角速度通道按 Roll/Pitch 命名，速度通道按 VX/VY 命名。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | Roll 目标角 | deg |
| I1 | Roll 反馈角 | deg |
| I2 | Pitch 目标角 | deg |
| I3 | Pitch 反馈角 | deg |
| I4 | Roll 轴目标角速度 | deg/s |
| I5 | Roll 轴实际角速度 | deg/s |
| I6 | Pitch 轴目标角速度 | deg/s |
| I7 | Pitch 轴实际角速度 | deg/s |
| I8 | 惯性系X目标速度 | cm/s |
| I9 | 惯性系X融合反馈速度 | cm/s |
| I10 | 惯性系Y目标速度 | cm/s |
| I11 | 惯性系Y融合反馈速度 | cm/s |
| I12 | 惯性系X位置误差 | cm |
| I13 | 惯性系Y位置误差 | cm |
| I14 | F2 帧序号，达到 1000000 后归零 | 帧 |
| I15 | 相邻 F2 帧发送间隔 | ms |

重点观察：目标与反馈方向是否一致、起飞后是否出现某一层明显发散。I14 正常应逐帧加 1，跳号表示接收端漏帧；I15 第一帧为 0，之后反映飞控端相邻两次 F2 发送之间的时间。

角度模式 KEY3 缓启动顺序为：1 秒零输出、1.2 秒四电机等值软起转到 300、0.5 秒 300 怠速保持、3 秒姿态闭环渐升到 750，最后在 3 秒内把高度目标从当前高度平滑升到 110 cm。前三个阶段不运行姿态 PID，`HEIGHT BLEND` 之前高度 PID 输出始终为 0。Flight View 会显示当前阶段；任意按键仍立即急停。

MANUAL 模式仅用于拆桨或固定台架测试，不运行姿态、角速度、速度和位置闭环。未解锁时可用 KEY1/KEY2 以 50 为步进调整预设油门，允许值为 0 或 300～2000；KEY3 安全检查并解锁成功后，将该预设值送入共享油门斜坡并等值输出到四个电机。解锁后四个实体按键仍全部作为急停，不再用于调节油门。

起飞前和缓启动期间不再使用 ToF 有效状态拒绝解锁或触发急停。正常飞行中仍持续判断 ToF；无效时高度 PID 输出清零并复位，基础油门和姿态环继续运行。

通过实体按键急停后，飞控强制保持 2 秒重新解锁禁止期。期间 Flight View 显示 `ESTOP LOCK - WAIT 2S`，重复按 KEY3 不会清除急停锁存；2 秒结束后再次按 KEY3 才能重新执行安全检查和缓启动。

Flight View 内置起飞诊断区：进入任一起飞阶段后显示绿色 `STARTING`、当前阶段和阶段进度；KEY3 请求被拒绝或起飞状态机中途退出后显示红色 `STOP`，并以 6×8 小字体显示停止原因、源文件 basename、代码行号和被中止时的状态。诊断区使用屏幕 `y=224-287`，底部两行提示仍位于 `y=288/304`，不会超过 IPS200 竖屏 320 像素高度。

用途：不依赖传感器验证 UART、无线链路和 JustFloat 解码。

| --- | --- |
| I0 | 在 0 到 100 之间往返变化的三角波 |

## F4：IMU 原始量与处理量

用途：检查 IMU 轴向、量程转换、静止噪声、加速度模值和校准状态。

| 通道 | 数据 |
| --- | --- |
| I0-I2 | 陀螺仪 X/Y/Z 原始值 |
| I3-I5 | 陀螺仪 X/Y/Z 转换值 |
| I6-I8 | 加速度计 X/Y/Z 原始值 |
| I9-I11 | 加速度计 X/Y/Z 转换值 |
| I12 | `acc` 加速度模值 |
| I13 | 姿态解算使用的滤波后加速度模值 |
| I14 | IMU 健康故障位掩码，0 表示当前无故障 |
| I15 | 姿态有效标志：0 无效、1 有效 |

静止时应重点观察 I3-I5 是否接近零、I13 是否稳定。I14 的 bit0-bit4 依次表示非有限数、加速度模值异常、陀螺饱和、四元数异常和样本停更；无故障时 I14 为 0、I15 为 1。bit1（I14=2）出现时，Mahony 会把加速度修正权重降到最低，姿态主要由陀螺积分。飞行中 I14/I15 仅用于诊断和 Flight View 提示，不再直接触发急停；解锁时仍通过完整 IMU 健康检查决定是否允许启动。

Flight View 触发 `INVALID CTRL` 时会进一步显示具体原因：`ATTITUDE NAN/INF`、`GYRO NAN/INF`、`BASE THROTTLE NAN` 或 `MIXER OUTPUT NAN`。IMU 健康位本身不再触发飞行中急停。

## F5/F7/F9：三轴角速度环分项

用途：分别观察 Roll、Pitch、Yaw 角速度环的目标、反馈、PID 分项、输出限幅和四电机混控结果。使用 `F5!` 观察 Roll，使用 `F7!` 观察 Pitch，使用 `F9!` 观察 Yaw。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | 目标角速度 | deg/s |
| I1 | 实际角速度 | deg/s |
| I2 | 角速度误差：目标 - 实际 | deg/s |
| I3 | P 项输出 | 内部输出量 |
| I4 | I 项输出 | 内部输出量 |
| I5 | D 项输出 | 内部输出量 |
| I6 | 限幅前 P+I+D 总和 | 内部输出量 |
| I7 | 限幅后、实际进入混控的总输出 | 内部输出量 |
| I8 | 输出饱和标志 | 0/1 |
| I9 | 目标姿态角 | deg |
| I10 | 实际姿态角 | deg |
| I11 | 基础油门 | 0-2000 |
| I12-I15 | 电机 1-4 混控并限幅后的油门 | 0-2000 |

无饱和时 I3+I4+I5 应等于 I6，I6 应等于 I7；发生输出限幅时 I8 为 1，I7 保持在角速度环输出限幅内。Yaw 为匹配实际混控方向，I3-I7 已统一反号，因此仍满足分项相加关系，但 P 项符号与 `Kp × I2` 相反。

## F6：姿态角环与角速度环

用途：姿态内外环的主要调参页面。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | Roll 目标角 | deg |
| I1 | Roll 反馈角 | deg |
| I2 | Roll 目标角速度 | deg/s |
| I3 | Roll 陀螺反馈 | deg/s |
| I4 | Roll 控制输出 | 内部输出量 |
| I5 | Pitch 目标角 | deg |
| I6 | Pitch 反馈角 | deg |
| I7 | Pitch 目标角速度 | deg/s |
| I8 | Pitch 陀螺反馈 | deg/s |
| I9 | Pitch 控制输出 | 内部输出量 |
| I10 | Yaw 目标角 | deg |
| I11 | Yaw 反馈角 | deg |
| I12 | Yaw 目标角速度 | deg/s |
| I13 | Yaw 陀螺反馈 | deg/s |
| I14 | Yaw 控制输出 | 内部输出量 |
| I15 | Yaw 最短角误差，范围 `[-180, 180)` | deg |

Yaw 外环使用 `wrap180(目标角-反馈角)`，因此反馈跨越 `+180°/-180°` 时 I15 应连续，例如目标 `179°`、反馈 `-179°` 时 I15 应为 `-2°`，不能出现 `358°`。先观察目标角速度与陀螺反馈，再观察目标角与姿态反馈；内环没有稳定前不要继续提高外环增益。飞行中 Yaw 陀螺反馈绝对值连续超过 `200°/s` 达 `150 ms` 会触发 `ESTOP YAW SPIN`，并锁定重新起飞 `2 s`。

## F8：水平速度闭环

用途：同时检查惯性系X/Y水平速度PID的目标、反馈、误差、加速度前馈和最终加速度。目标加速度随后按Yaw转回机体系并解算为Pitch/Roll目标角。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | X 轴目标速度 | cm/s |
| I1 | X 轴融合反馈速度 | cm/s |
| I2 | X 轴速度误差：目标 - 反馈 | cm/s |
| I3 | X 轴 P 项加速度修正 | cm/s² |
| I4 | X 轴 I 项加速度修正 | cm/s² |
| I5 | X 轴 D 项加速度修正 | cm/s² |
| I6 | X 轴轨迹加速度前馈 | cm/s² |
| I7 | X 轴最终目标加速度 | cm/s² |
| I8 | Y 轴目标速度 | cm/s |
| I9 | Y 轴融合反馈速度 | cm/s |
| I10 | Y 轴速度误差：目标 - 反馈 | cm/s |
| I11 | Y 轴 P 项加速度修正 | cm/s² |
| I12 | Y 轴 I 项加速度修正 | cm/s² |
| I13 | Y 轴 D 项加速度修正 | cm/s² |
| I14 | Y 轴轨迹加速度前馈 | cm/s² |
| I15 | Y 轴最终目标加速度 | cm/s² |

未发生二维加速度限幅时应满足`I7=I3+I4+I5+I6`，Y轴对应`I15=I11+I12+I13+I14`。调参前必须先确认推动机体时惯性系反馈速度符号正确。

D项只对惯性系实际融合速度做负微分，不包含目标速度变化率；微分原始值先限制在`±400 cm/s²`，再按实际`4 ms dt`经过250 Hz设计、5 Hz截止、Q=0.7071的二阶Biquad低通，最终D项输出限制在`±120 cm/s²`。P/I/D与轨迹加速度前馈之和受二维水平加速度/15°倾角限制；混控器高端或低端饱和时，积分只允许向退出饱和的方向变化。

<a id="ft"></a>
## FT：姿态优先混控与限幅

用途：观察`Roll/Pitch > Yaw > 公共油门`控制分配结果。发送`FT!`后持续输出16路JustFloat数据；内部模式编号为42。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0-I3 | M1-M4按原始请求直接相加得到的电机量 | 0-2000附近 |
| I4-I7 | M1-M4经过优先级分配后的电机量 | 0-2000 |
| I8 | Roll/Pitch统一缩放比例 | 0-1 |
| I9 | Yaw缩放比例 | 0-1 |
| I10 | 倾角补偿后的请求公共油门 | 0-2000附近 |
| I11 | 分配器实际采用的公共油门 | 0-2000附近 |
| I12 | Roll方向限幅标志 | bit0正向，bit1负向 |
| I13 | Pitch方向限幅标志 | bit0正向，bit1负向 |
| I14 | Yaw方向限幅标志 | bit0正向，bit1负向 |
| I15 | 公共油门方向限幅标志 | bit0上限，bit1下限 |

正常未受限时`I8=I9=1`、`I10=I11`且`I12-I15=0`。仅`I9<1`表示为保留Roll/Pitch而削减Yaw；仅`I10!=I11`表示姿态差动完整保留、公共油门被平移。只有`I8<1`时Roll/Pitch本身已经超过全部电机动态范围，属于最严重的姿态控制饱和。

## FV/FW：X/Y 速度环 PID 分项

用途：像`F5/F7`检查角速度环一样，检查惯性系X/Y速度PID的目标、反馈、加速度分项和后级姿态跟随。使用`FV!`观察X速度环，使用`FW!`观察Y速度环。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | 目标速度 | cm/s |
| I1 | 融合反馈速度 | cm/s |
| I2 | 速度误差：目标 - 反馈 | cm/s |
| I3 | P 项加速度修正 | cm/s² |
| I4 | I 项加速度修正 | cm/s² |
| I5 | D 项加速度修正 | cm/s² |
| I6 | 轨迹加速度前馈 | cm/s² |
| I7 | 最终目标加速度 | cm/s² |
| I8 | 速度 PID 输出饱和标志 | 0/1 |
| I9 | 最终目标 Pitch/Roll 角 | deg |
| I10 | 实际 Pitch/Roll 角 | deg |
| I11 | 最终目标 Pitch/Roll 角速度 | deg/s |
| I12 | 实际 Pitch/Roll 角速度 | deg/s |
| I13 | 目标角变化率前馈输出 | deg/s |
| I14 | 速度环当前有效参与控制 | 0/1 |
| I15 | 基础油门 | 0-2000 |

未发生二维加速度限幅时，两种模式都应满足`I3+I4+I5+I6=I7`。I8为1表示X/Y合成后的目标加速度受到二维限幅。I9-I13仍按FV显示Pitch、FW显示Roll，只有Yaw接近零方向时才能把单个惯性轴与该姿态轴直接对应；其他航向应结合`FN`观察完整二维加速度。

调参时先看 I0/I1 是否存在速度反馈滞后，再看 I3-I8 判断 PID 增益或饱和问题。若 I7 已快速变化但 I9/I10 仍明显分离，瓶颈在姿态角跟随；若 I11/I12 也明显分离，应优先处理角速度内环。I14 为 0 时，本帧 PID 分项已经清零，不应使用该段数据评价增益。

## FG：姿态目标角变化率前馈

用途：检查速度环目标角变化率、前馈角速度和姿态内外环跟随。发送 `FG!` 后持续输出 16 路 JustFloat 数据。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | Roll 目标角 | deg |
| I1 | Roll 反馈角 | deg |
| I2 | Roll 原始目标角变化率 | deg/s |
| I3 | Roll 15 Hz 滤波目标角变化率 | deg/s |
| I4 | Roll 角度外环输出目标角速度 | deg/s |
| I5 | Roll 前馈角速度 | deg/s |
| I6 | Roll 最终目标角速度（含 26 Hz 低通） | deg/s |
| I7 | Roll 实际角速度 | deg/s |
| I8 | Pitch 目标角 | deg |
| I9 | Pitch 反馈角 | deg |
| I10 | Pitch 原始目标角变化率 | deg/s |
| I11 | Pitch 15 Hz 滤波目标角变化率 | deg/s |
| I12 | Pitch 角度外环输出目标角速度 | deg/s |
| I13 | Pitch 前馈角速度 | deg/s |
| I14 | Pitch 最终目标角速度（含 26 Hz 低通） | deg/s |
| I15 | Pitch 实际角速度 | deg/s |

前馈只改变目标角速度，不改变 Roll/Pitch 目标角。目标角稳定后 I2/I3/I5 或 I10/I11/I13 应回到零。默认前馈增益为零，因此首次烧录后的控制行为不变。若后续打开姿态 sqrt 接管，I4/I12 表示 sqrt_controller 选中的外环输出，不再表示传统 PID 的 P/I/D 总和。

## FX：姿态 sqrt_controller 旁路诊断

用途：在不改变默认控制行为的前提下，对比 Roll/Pitch 角度外环的线性 P 输出和 sqrt_controller 输出。发送 `FX!` 后持续输出 16 路 JustFloat 数据。

当前默认宏配置为：

```c
#define ANGLE_LOOP_SQRT_CONTROL_ENABLE      (0U)
#define ANGLE_LOOP_SQRT_BYPASS_DIAG_ENABLE  (1U)
#define ANGLE_LOOP_SQRT_ACCEL_MAX_DPS2      (720.0f)
```

默认状态下 `CONTROL_ENABLE=0`，飞行仍使用原来的角度外环 PID；`BYPASS_DIAG_ENABLE=1` 只额外计算两轴 sqrt 对比值。若 `BYPASS_DIAG_ENABLE=0`，`FX` 页面不再更新旁路对比数据，不应作为有效诊断依据。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | Roll 角度误差：目标角 - 反馈角 | deg |
| I1 | Roll 线性 P 目标角速度：`Kp × 角度误差`，已按外环输出限幅裁剪 | deg/s |
| I2 | Roll sqrt_controller 目标角速度，已按外环输出限幅裁剪 | deg/s |
| I3 | Roll 当前实际选中的外环输出；默认等于原 PID 输出，sqrt 接管后等于 I2 | deg/s |
| I4 | Roll 目标角变化率前馈 | deg/s |
| I5 | Roll 限幅后目标角速度，进入 26 Hz 低通前 | deg/s |
| I6 | Roll 最终目标角速度，进入角速度环 | deg/s |
| I7 | Roll 实际角速度 | deg/s |
| I8 | Pitch 角度误差：目标角 - 反馈角 | deg |
| I9 | Pitch 线性 P 目标角速度：`Kp × 角度误差`，已按外环输出限幅裁剪 | deg/s |
| I10 | Pitch sqrt_controller 目标角速度，已按外环输出限幅裁剪 | deg/s |
| I11 | Pitch 当前实际选中的外环输出；默认等于原 PID 输出，sqrt 接管后等于 I10 | deg/s |
| I12 | Pitch 目标角变化率前馈 | deg/s |
| I13 | Pitch 限幅后目标角速度，进入 26 Hz 低通前 | deg/s |
| I14 | Pitch 最终目标角速度，进入角速度环 | deg/s |
| I15 | Pitch 实际角速度 | deg/s |

调参判断：

1. 先用 `F5/F7` 确认角速度内环能跟住目标角速度，再看 `F6/FX`。内环没稳定前，不要根据 `FX` 调姿态外环。
2. 默认旁路诊断时，`I3/I11` 仍是原 PID 外环输出；如果 Roll/Pitch 外环 Ki/Kd 不为 0，`I3` 可能与 `I1` 略有差异，这是积分或微分造成的，不是 sqrt 生效。
3. 若 `I1` 与 `I2`、`I9` 与 `I10` 基本重合，且 `I5/I13` 很少打到外环输出限幅，说明当前线性 P 已经足够，暂时没有必要启用 sqrt 接管。
4. 若位置环或目标角突变时，`I1/I9` 明显大于 `I2/I10`，并且 `I6/I14` 或实际角速度出现冲击、过冲、限幅，则可以考虑打开 `ANGLE_LOOP_SQRT_CONTROL_ENABLE=1` 试飞。
5. `ANGLE_LOOP_SQRT_ACCEL_MAX_DPS2` 越小，姿态目标角速度越软，抗过冲更强但响应更慢；越大越接近线性 P，响应更快但更容易把内环推到限幅。第一版建议只改这个宏和 Roll/Pitch 外环 Kp，不同时调外环 Ki/Kd。
6. 打开 sqrt 接管后，`R2/R3/P2/P3` 参数入口仍保留，但第一版 Roll/Pitch 外环输出不使用 Ki/Kd。角速度内环 `r/p` 参数仍正常生效。
7. 每次切换宏或修改加速度上限后，先拆桨地面拨动看 `FX/FY`，确认无 NaN、无持续超期；再低高度、小角度试飞。

有效原始距离为 `2～200 cm`。正常测量需要满足动态门 `5 cm + 100 cm/s × 最近可信高度年龄`，动态门最大为 `20 cm`。进入候选状态后暂时冻结首次拒绝时的门限，防止门限随保持时间增大而提前接受同一跳变；测量回到原可信轨迹后仍可立即恢复 LIVE。门外测量不会进入中值、低通和速度差分；候选与候选均值相差不超过 `10 cm` 时累计，连续 5 帧一致后重捕获。累计 10 个门外帧仍无法形成稳定候选时，I15 置 0。

轮询暂时没有新帧时保留上一可信高度；连续 `100 ms` 没有有效范围帧才失效。首个有效帧直接初始化，初始化前高度为 0 且 I15 为 0，不再显示虚假的 100 cm 初始高度。

| I14 | 小驱板待发最大延迟 | us |
| I15 | 小驱板软件 FIFO 错误次数 | 次 |

本机上电后使用连续 20 个有效样本自动识别并锁存 4S 或 6S，飞行中不会重新切换串数。4S 识别范围是 12.0-17.2 V，6S 识别范围是 18.0-25.8 V；无法识别或采样失效时，I4 为 0。KEY3启动时，本机滤波电压低于 12.5 V 会以 `BAT LOW` 拒绝解锁；该门限只在解锁前检查，不参与飞行过程。未解锁时 I4=0 会拒绝启动并禁止测试输出；已经解锁后 I4 变为 0 不再触发急停，电机继续使用最后一次可信的补偿电压、增益和硬输出上限。

两种电池都以 15.2 V 为动力补偿参考，补偿增益按 `(15.2 / 本机电压) × 0.94` 计算，仅保留 0.55 的低增益下限，不限制低电压侧的增益上限。4S 低压警告/恢复阈值为 14.8/15.2 V，6S 为 22.2/22.8 V。未解锁或处于测试模式时，电压采样无效仍禁止输出；飞行中则保持最后可信输出参数。最终电机输出始终限制在 0-2000。Motor Test 只能绕过单电机一致性修正，不能绕过电压补偿和最终硬输出上限。

飞机本机电压使用 E1 母板官方检测通道 `P07_5 / ADC0_CH21`，12 位 ADC 按 `36.3 / 4096` 换算。Flight View 的 `BAT` 与 FZ 的 I1 都显示该本机滤波电压；FZ 的 I4 为 1 时使用实时电压补偿，飞行中 I4 变为 0 时进入最后可信值保持。此时 IPS200 以约 500 ms 的红屏/正常页面周期闪烁，红屏显示 `BAT INVALID`，但不撤销解锁或清零电机。为避免短暂无效事件落在屏幕刷新间隔内而不可见，采样恢复后红屏告警仍保持 2 秒。I11 的位掩码同时表示常规 0-2000 饱和和按补偿电压计算的最终硬限幅。

<a id="attitude-commands"></a>
## 姿态角环与角速度环调参指令

通用格式：`命令字符 + 参数编号 = 数值 + !`。

有效调参值成功写入后，主板 `P19_4` 蜂鸣器会短响两声作为确认。查询命令、波形切换、急停命令以及参数编号无效的写入不会触发提示音；提示音由 5 ms 周期任务非阻塞播放，不会暂停控制任务或 VOFA 收发。

| 命令 | 控制器 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| R | Roll 角度环 | Kp | Ki | Kd | - |
| P | Pitch 角度环 | Kp | Ki | Kd | - |
| Y | Yaw 角度环 | Kp | Ki | Kd | - |
| r | Roll 角速度环 | Kp | Ki | Kd | 积分限幅 |
| p | Pitch 角速度环 | Kp | Ki | Kd | 积分限幅 |
| y | Yaw 角速度环 | Kp | Ki | Kd | 积分限幅 |

示例：

```text
R1=2.5!
p3=0.4!
r4=100!
```

发送不带数值的命令可以读取当前参数，例如 `R0!`、`p0!`。

## 速度环调参指令

| 命令 | 控制器 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| V | 惯性系X速度环 | Kp | Ki | Kd | 加速度输出限幅（cm/s²） | I项加速度限幅（cm/s²） | Pitch目标角速度前馈增益 | Pitch前馈限幅（deg/s） | D低通（Hz） |
| W | 惯性系Y速度环 | Kp | Ki | Kd | 加速度输出限幅（cm/s²） | I项加速度限幅（cm/s²） | Roll目标角速度前馈增益 | Roll前馈限幅（deg/s） | D低通（Hz） |

速度PID输出水平加速度修正，与轨迹加速度前馈相加后做二维限幅，再结合重力矢量解算Pitch/Roll目标角。默认`Kp=2.0、Ki=1.0、Kd=0.20`，加速度限幅`263 cm/s²`，I项限幅`80 cm/s²`。目标角变化率前馈仍位于角度PID之后，不改变目标角。D低通合法范围为`1～50 Hz`，默认`5 Hz`；V8/W8修改的是二阶Biquad截止频率。

## 位置环调参指令

| 命令 | 控制器 | 0 | 1 |
| --- | --- | --- | --- |
| I/J | 二维位置环兼容入口 | 启用/关闭位置环 | 统一位置P |

`I0=1!`或`J0=1!`会启用整个位置环。ArduPilot式二维位置控制只使用统一P增益，`I1`和`J1`都会同时修改X/Y；旧的I/J参数2～5不再接受写入。

小车速度前馈与二维轨迹参数使用独立命令：

| 命令 | 含义 | 范围 |
| --- | --- | --- |
| `M1=数值!` | X小车速度前馈增益 | 0～1.2 |
| `M2=数值!` | Y小车速度前馈增益 | 0～1.2 |
| `M3=数值!` | 二维位置P增益 | 0.05～3.0 s⁻¹ |
| `M4=数值!` | 位置修正速度模长上限 | 10～200 cm/s |
| `M5=数值!` | 最终目标速度模长上限 | 20～300 cm/s |
| `M6=数值!` | 已删除的无人机速度整形加速度参数，拒绝设置 | - |
| `M7=数值!` | 已删除的无人机速度整形Jerk参数，拒绝设置 | - |
| `M8=数值!` | P/Sqrt纠偏包络加速度 | 5～400 cm/s² |
| `M!` | 查询M1～M8 | - |

`M!`查询返回：I0/I1前馈增益，I2位置P，I3位置修正速度上限，I4最终目标速度上限，I5/I6保留为0，I7纠偏包络加速度。

默认值以 `position_loop.c` 当前宏为准。真实位置误差先由P/Sqrt控制器生成纠偏速度，小车速度前馈与纠偏速度独立计算，合成后只经过M5二维速度限幅；小车计划加速度作为独立前馈进入速度环。

安全速度包络使用独立的N组参数：

| 命令 | 含义 | 范围 |
| --- | --- | --- |
| `N1=数值!` | A/J安全速度模型有效加速度 | 10～400 cm/s² |
| `N2=数值!` | A/J安全速度模型有效Jerk | 20～1000 cm/s³ |
| `N3=数值!` | 控制链路等效延迟 | 0～500 ms |
| `N4=数值!` | A/J安全余量 | 0～100 cm |
| `N5=数值!` | A/J速度包络提前收紧宽度 | 0～100 cm |
| `N6=数值!` | 已删除的增强制动整形加速度参数，拒绝设置 | - |
| `N7=数值!` | 已删除的增强制动整形Jerk参数，拒绝设置 | - |
| `N!` | 查询N1～N5 | - |

`N!`查询返回I0～I4依次对应N1～N5，I5～I15保留为0。默认值以`position_loop.c`当前宏为准。

N1/N2是根据实飞减速曲线标定的无人机有效制动加速度和Jerk，用于把距离反解为允许的位置纠偏接近速度。N3是等效延迟，N4是安全余量，N5是安全速度包络提前收紧宽度，三者默认均为0。每周期将位置纠偏速度限制为`min(v_corr_nominal, v_allow)`；该限制器不直接写入角度环、不限制目标速度变化率，也不改写小车速度和加速度前馈。

<a id="tuning-order"></a>
## 飞行调参建议顺序

1. `F3`：确认通信链路连续。
2. `F4`：确认 IMU 轴向、静止噪声和校准状态。
3. `FZ`：确认电池电压、补偿增益和电机输出没有饱和。
4. `FY`：确认控制任务没有持续超期。
5. `F5/F7/F9`：分别调 Roll、Pitch、Yaw 角速度内环，并检查 PID 分项与电机输出饱和。
6. `F6`：角速度内环稳定后，再调姿态外环。
7. `FX`：对比姿态外环线性 P 与 sqrt_controller。只有线性 P 经常过猛、限幅或造成跟随冲击时，才考虑打开 sqrt 接管。
8. `FD`：调高度位置环与垂直速度环。
9. `FU1`/`FU2`：逐轴确认实时融合速度、光流纠偏和观测新鲜度。
10. `F8`：调水平速度环。
11. `FI`：地面确认视觉位置方向后，再从很小的 Kp 开始调位置环。
12. `F2`：最后用全局总览检查各层闭环协同。

每次只改变一个参数，并记录修改前数值、修改后数值、电池电压和对应波形。自动位置闭环第一次测试应限制高度、速度和姿态修正量，并确保可以立即发送 `00!` 或使用机身急停操作。
