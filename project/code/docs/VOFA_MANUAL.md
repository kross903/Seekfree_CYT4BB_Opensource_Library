## 连接与命令格式

| 项目 | 当前配置 |
| --- | --- |
| 串口 | UART1 |
| 波特率 | 115200 |
| 数据协议 | VOFA+ JustFloat |
| 帧尾 | `00 00 80 7F` |
| 波形通道 | 8 路或 16 路 float |
| 命令结束符 | `!` |

所有命令必须以 `!` 结尾，例如：

```text
F6!
R1=2.5!
00!
```

拨码 `P09_0` 和 `P09_1` 同时为低电平时，UART1 被切换到逐飞助手图像模式，此时 VOFA 收发停止。调参时应保证没有同时进入图像模式。

发送某个 `F` 指令后，固件会持续发送该模式，直到收到另一个有效的 `F` 指令。通道编号按 VOFA 中的 `I0`、`I1`……排列。

## F2：全局飞行总览

用途：起飞和综合联调时统一观察姿态、高度、速度与位置。该页面用于快速判断问题属于哪一层，不适合代替各闭环专用页面做精调。

本工程坐标约定：

- 平移速度 `VX`：机体前后方向，正值表示向前。
- 平移速度 `VY`：机体左右方向，正值表示向左。
- 旋转角速度按姿态轴命名：Roll 为横滚轴，Pitch 为俯仰轴，Yaw 为偏航轴。
- 速度环控制映射固定为：`VX → Pitch` 修正，`VY → Roll` 修正。

注意：平移速度的 `VX/VY` 与旋转角速度的 Roll/Pitch 不是同一组轴名称。F2 的角速度通道按 Roll/Pitch 命名，速度通道按 VX/VY 命名。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | Roll 目标角 | deg |
| I1 | Roll 反馈角 | deg |
| I2 | Pitch 目标角 | deg |
| I3 | Pitch 反馈角 | deg |
| I4 | Roll 轴目标角速度 | deg/s |
| I5 | Roll 轴实际角速度 | deg/s |
| I6 | Pitch 轴目标角速度 | deg/s |
| I7 | Pitch 轴实际角速度 | deg/s |
| I8 | VX（机体前后）目标速度 | cm/s |
| I9 | VX（机体前后）融合反馈速度 | cm/s |
| I10 | VY（机体左右）目标速度 | cm/s |
| I11 | VY（机体左右）融合反馈速度 | cm/s |
| I12 | X 方向位置误差 | cm |
| I13 | Y 方向位置误差 | cm |
| I14 | F2 帧序号，达到 1000000 后归零 | 帧 |
| I15 | 相邻 F2 帧发送间隔 | ms |

重点观察：目标与反馈方向是否一致、起飞后是否出现某一层明显发散。I14 正常应逐帧加 1，跳号表示接收端漏帧；I15 第一帧为 0，之后反映飞控端相邻两次 F2 发送之间的时间。

角度模式 KEY3 缓启动顺序为：1 秒零输出、1.2 秒四电机等值软起转到 300、0.5 秒 300 怠速保持、3 秒姿态闭环渐升到 750，最后在 3 秒内把高度目标从当前高度平滑升到 110 cm。前三个阶段不运行姿态 PID，`HEIGHT BLEND` 之前高度 PID 输出始终为 0。Flight View 会显示当前阶段；任意按键仍立即急停。

起飞前和缓启动期间不再使用 ToF 有效状态拒绝解锁或触发急停。正常飞行中仍持续判断 ToF；无效时高度 PID 输出清零并复位，基础油门和姿态环继续运行。

通过实体按键急停后，飞控强制保持 2 秒重新解锁禁止期。期间 Flight View 显示 `ESTOP LOCK - WAIT 2S`，重复按 KEY3 不会清除急停锁存；2 秒结束后再次按 KEY3 才能重新执行安全检查和缓启动。

Flight View 内置起飞诊断区：进入任一起飞阶段后显示绿色 `STARTING`、当前阶段和阶段进度；KEY3 请求被拒绝或起飞状态机中途退出后显示红色 `STOP`，并以 6×8 小字体显示停止原因、源文件 basename、代码行号和被中止时的状态。诊断区使用屏幕 `y=224-287`，底部两行提示仍位于 `y=288/304`，不会超过 IPS200 竖屏 320 像素高度。

## F3：VOFA 通信测试

用途：不依赖传感器验证 UART、无线链路和 JustFloat 解码。

| 通道 | 数据 |
| --- | --- |
| I0 | 在 0 到 100 之间往返变化的三角波 |
| I1-I7 | 0 |

如果 I0 不连续、停顿或跳变，先处理通信问题，不要直接判断控制环有故障。

## F4：IMU 原始量与处理量

用途：检查 IMU 轴向、量程转换、静止噪声、加速度模值和校准状态。

| 通道 | 数据 |
| --- | --- |
| I0-I2 | 陀螺仪 X/Y/Z 原始值 |
| I3-I5 | 陀螺仪 X/Y/Z 转换值 |
| I6-I8 | 加速度计 X/Y/Z 原始值 |
| I9-I11 | 加速度计 X/Y/Z 转换值 |
| I12 | `acc` 加速度模值 |
| I13 | 姿态解算使用的滤波后加速度模值 |
| I14 | IMU 健康故障位掩码，0 表示当前无故障 |
| I15 | 姿态有效标志：0 无效、1 有效 |

静止时应重点观察 I3-I5 是否接近零、I13 是否稳定。I14 的 bit0-bit4 依次表示非有限数、加速度模值异常、陀螺饱和、四元数异常和样本停更；无故障时 I14 为 0、I15 为 1。bit1（I14=2）出现时，Mahony 会把加速度修正权重降到最低，姿态主要由陀螺积分。飞行中 I14/I15 仅用于诊断和 Flight View 提示，不再直接触发急停；解锁时仍通过完整 IMU 健康检查决定是否允许启动。

Flight View 触发 `INVALID CTRL` 时会进一步显示具体原因：`ATTITUDE NAN/INF`、`GYRO NAN/INF`、`BASE THROTTLE NAN` 或 `MIXER OUTPUT NAN`。IMU 健康位本身不再触发飞行中急停。

## F5/F7/F9：三轴角速度环分项

用途：分别观察 Roll、Pitch、Yaw 角速度环的目标、反馈、PID 分项、输出限幅和四电机混控结果。使用 `F5!` 观察 Roll，使用 `F7!` 观察 Pitch，使用 `F9!` 观察 Yaw。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | 目标角速度 | deg/s |
| I1 | 实际角速度 | deg/s |
| I2 | 角速度误差：目标 - 实际 | deg/s |
| I3 | P 项输出 | 内部输出量 |
| I4 | I 项输出 | 内部输出量 |
| I5 | D 项输出 | 内部输出量 |
| I6 | 限幅前 P+I+D 总和 | 内部输出量 |
| I7 | 限幅后、实际进入混控的总输出 | 内部输出量 |
| I8 | 输出饱和标志 | 0/1 |
| I9 | 目标姿态角 | deg |
| I10 | 实际姿态角 | deg |
| I11 | 基础油门 | 0-2000 |
| I12-I15 | 电机 1-4 混控并限幅后的油门 | 0-2000 |

无饱和时 I3+I4+I5 应等于 I6，I6 应等于 I7；发生输出限幅时 I8 为 1，I7 保持在角速度环输出限幅内。Yaw 为匹配实际混控方向，I3-I7 已统一反号，因此仍满足分项相加关系，但 P 项符号与 `Kp × I2` 相反。

## F6：姿态角环与角速度环

用途：姿态内外环的主要调参页面。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | Roll 目标角 | deg |
| I1 | Roll 反馈角 | deg |
| I2 | Roll 目标角速度 | deg/s |
| I3 | Roll 陀螺反馈 | deg/s |
| I4 | Roll 控制输出 | 内部输出量 |
| I5 | Pitch 目标角 | deg |
| I6 | Pitch 反馈角 | deg |
| I7 | Pitch 目标角速度 | deg/s |
| I8 | Pitch 陀螺反馈 | deg/s |
| I9 | Pitch 控制输出 | 内部输出量 |
| I10 | Yaw 目标角 | deg |
| I11 | Yaw 反馈角 | deg |
| I12 | Yaw 目标角速度 | deg/s |
| I13 | Yaw 陀螺反馈 | deg/s |
| I14 | Yaw 控制输出 | 内部输出量 |
| I15 | Yaw 最短角误差，范围 `[-180, 180)` | deg |

Yaw 外环使用 `wrap180(目标角-反馈角)`，因此反馈跨越 `+180°/-180°` 时 I15 应连续，例如目标 `179°`、反馈 `-179°` 时 I15 应为 `-2°`，不能出现 `358°`。先观察目标角速度与陀螺反馈，再观察目标角与姿态反馈；内环没有稳定前不要继续提高外环增益。飞行中 Yaw 陀螺反馈绝对值连续超过 `200°/s` 达 `150 ms` 会触发 `ESTOP YAW SPIN`，并锁定重新起飞 `2 s`。

## F8：水平速度闭环

用途：同时检查 X→Pitch 和 Y→Roll 两个水平速度 PID 的目标、反馈、误差、P/I/D 分项及最终修正角。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | X 轴目标速度 | cm/s |
| I1 | X 轴融合反馈速度 | cm/s |
| I2 | X 轴速度误差：目标 - 反馈 | cm/s |
| I3 | X 轴 P 项输出 | deg |
| I4 | X 轴 I 项输出 | deg |
| I5 | X 轴 D 项输出 | deg |
| I6 | X 轴限幅前 P+I+D 总和 | deg |
| I7 | X 轴最终 Pitch 修正角 | deg |
| I8 | Y 轴目标速度 | cm/s |
| I9 | Y 轴融合反馈速度 | cm/s |
| I10 | Y 轴速度误差：目标 - 反馈 | cm/s |
| I11 | Y 轴 P 项输出 | deg |
| I12 | Y 轴 I 项输出 | deg |
| I13 | Y 轴 D 项输出 | deg |
| I14 | Y 轴限幅前 P+I+D 总和 | deg |
| I15 | Y 轴最终 Roll 修正角 | deg |

X 轴速度通过 Pitch 修正，Y 轴速度通过 Roll 修正。未发生输出限幅时应满足 `I3+I4+I5=I6=I7`，Y 轴对应 `I11+I12+I13=I14=I15`；发生限幅时，I7/I15 为最终受限输出。调参前必须先确认推动机体时反馈速度符号正确。

D项只对实际融合速度做负微分，不包含目标速度变化率。D支路依次经过三帧中值、`±900 cm/s²`变化率限幅和按实际`dt`计算的8 Hz一阶低通；这些处理不作用于P/I使用的融合速度。D项不设置独立输出限幅，最终仍受速度PID总输出`±10°`限制。

## FV/FW：X/Y 速度环 PID 分项

用途：像 `F5/F7` 检查角速度环一样，检查速度 PID 的目标、反馈、P/I/D 分项、饱和状态以及后级姿态跟随。使用 `FV!` 观察 X→Pitch 速度环，使用 `FW!` 观察 Y→Roll 速度环。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | 目标速度 | cm/s |
| I1 | 融合反馈速度 | cm/s |
| I2 | 速度误差：目标 - 反馈 | cm/s |
| I3 | P 项输出 | deg |
| I4 | I 项输出 | deg |
| I5 | D 项输出 | deg |
| I6 | 限幅前 P+I+D 总和 | deg |
| I7 | 限幅后的 Pitch/Roll 修正角 | deg |
| I8 | 速度 PID 输出饱和标志 | 0/1 |
| I9 | 最终目标 Pitch/Roll 角 | deg |
| I10 | 实际 Pitch/Roll 角 | deg |
| I11 | 最终目标 Pitch/Roll 角速度 | deg/s |
| I12 | 实际 Pitch/Roll 角速度 | deg/s |
| I13 | 目标角变化率前馈输出 | deg/s |
| I14 | 速度环当前有效参与控制 | 0/1 |
| I15 | 基础油门 | 0-2000 |

`FV` 的 I3-I7 使用实际 Pitch 修正方向；`FW` 的 I3-I7 已乘以 Y→Roll 的负号，使用实际 Roll 修正方向。因此两种模式在未饱和时都应满足 `I3+I4+I5=I6=I7`。I8 为 1 时，I7 已被速度 PID 的输出限幅截断。

调参时先看 I0/I1 是否存在速度反馈滞后，再看 I3-I8 判断 PID 增益或饱和问题。若 I7 已快速变化但 I9/I10 仍明显分离，瓶颈在姿态角跟随；若 I11/I12 也明显分离，应优先处理角速度内环。I14 为 0 时，本帧 PID 分项已经清零，不应使用该段数据评价增益。

## FG：姿态目标角变化率前馈

用途：检查速度环目标角变化率、前馈角速度和姿态内外环跟随。发送 `FG!` 后持续输出 16 路 JustFloat 数据。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | Roll 目标角 | deg |
| I1 | Roll 反馈角 | deg |
| I2 | Roll 原始目标角变化率 | deg/s |
| I3 | Roll 15 Hz 滤波目标角变化率 | deg/s |
| I4 | Roll 角度 PID 目标角速度 | deg/s |
| I5 | Roll 前馈角速度 | deg/s |
| I6 | Roll 最终目标角速度（含 26 Hz 低通） | deg/s |
| I7 | Roll 实际角速度 | deg/s |
| I8 | Pitch 目标角 | deg |
| I9 | Pitch 反馈角 | deg |
| I10 | Pitch 原始目标角变化率 | deg/s |
| I11 | Pitch 15 Hz 滤波目标角变化率 | deg/s |
| I12 | Pitch 角度 PID 目标角速度 | deg/s |
| I13 | Pitch 前馈角速度 | deg/s |
| I14 | Pitch 最终目标角速度（含 26 Hz 低通） | deg/s |
| I15 | Pitch 实际角速度 | deg/s |

前馈只改变目标角速度，不改变 Roll/Pitch 目标角。目标角稳定后 I2/I3/I5 或 I10/I11/I13 应回到零。默认前馈增益为零，因此首次烧录后的控制行为不变。

## FA：水平加速度与惯导速度

用途：检查机体系加速度转到水平坐标后的零偏，以及纯惯导速度漂移趋势。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | 水平坐标 X 加速度 | mg |
| I1 | 水平坐标 Y 加速度 | mg |
| I2 | X 加速度水平零偏 | mg |
| I3 | Y 加速度水平零偏 | mg |
| I4 | X 去零偏加速度 | mg |
| I5 | Y 去零偏加速度 | mg |
| I6 | X 滤波后线速度 `X_V_F` | 工程速度单位 |
| I7 | Y 滤波后线速度 `Y_V_F` | 工程速度单位 |

机体静止且水平时，I4/I5 应围绕零小幅波动；I6/I7 长时间明显单向漂移说明加速度零偏仍需处理。

## FB：高度环诊断

用途：观察高度环和垂直速度环的 PID 分项，方便判断滞后和饱和发生在哪一层。
发送 `FB!` 后持续输出 16 路 JustFloat 数据；内部模式编号为 12。
| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | 目标高度 | cm |
| I1 | 实际高度 | cm |
| I2 | 高度环 P 项 | 输出量 |
| I3 | 高度环 I 项 | 输出量 |
| I4 | 高度环 D 项 | 输出量 |
| I5 | 高度环总输出 | 输出量 |
| I6 | 速度环目标垂直速度 | cm/s |
| I7 | 实际垂直速度（进入速度 PID 的强滤波反馈） | cm/s |
| I8 | 速度环 P 项 | 输出量 |
| I9 | 速度环 I 项 | 输出量 |
| I10 | 速度环 D 项 | 输出量 |
| I11 | 速度环总输出 | 输出量 |
| I12 | 高度误差 | cm |
| I13 | 速度误差 | cm/s |
| I14 | 速度环最终应用输出 | 输出量 |
| I15 | 高度串级使能 | 0/1 |

重点看 I2-I5 是否能解释 I0/I1 的变化，I8-I11 是否能解释 I6/I7 的变化。I14 是经过软起飞混合后的最终速度环输出，I11 是 PID 本体输出。

用途：采集安装矩阵求解需要的六面原始加速度。拆除桨叶后使用；每次摆好一个姿态，发送 `FC!` 并单独导出一份 CSV。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | 加速度计传感器 X 原始值 | count |
| I1 | 加速度计传感器 Y 原始值 | count |
| I2 | 加速度计传感器 Z 原始值 | count |
| I3 | 原始加速度模值 | count |
| I4 | 当前矩阵转换后的机体 X 加速度 | mg |

| I15 | 小驱板软件 FIFO 错误次数 | 次 |

本机上电后使用连续 20 个有效样本自动识别并锁存 4S 或 6S，飞行中不会重新切换串数。4S 识别范围是 12.0-17.2 V，6S 识别范围是 18.0-25.8 V；无法识别或采样失效时，I4 为 0。未解锁时 I4=0 会拒绝启动并禁止测试输出；已经解锁后 I4 变为 0 不再触发急停，电机继续使用最后一次可信的补偿电压、增益和硬输出上限。

两种电池都以 15.2 V 为动力补偿参考，补偿增益按 `(15.2 / 本机电压) × 0.94` 计算，仅保留 0.55 的低增益下限，不限制低电压侧的增益上限。4S 低压警告/恢复阈值为 14.8/15.2 V，6S 为 22.2/22.8 V。未解锁或处于测试模式时，电压采样无效仍禁止输出；飞行中则保持最后可信输出参数。最终电机输出始终限制在 0-2000。Motor Test 只能绕过单电机一致性修正，不能绕过电压补偿和最终硬输出上限。

飞机本机电压使用 E1 母板官方检测通道 `P07_5 / ADC0_CH21`，12 位 ADC 按 `36.3 / 4096` 换算。Flight View 的 `BAT` 与 FZ 的 I1 都显示该本机滤波电压；FZ 的 I4 为 1 时使用实时电压补偿，飞行中 I4 变为 0 时进入最后可信值保持。此时 IPS200 以约 500 ms 的红屏/正常页面周期闪烁，红屏显示 `BAT INVALID`，但不撤销解锁或清零电机。为避免短暂无效事件落在屏幕刷新间隔内而不可见，采样恢复后红屏告警仍保持 2 秒。I11 的位掩码同时表示常规 0-2000 饱和和按补偿电压计算的最终硬限幅。

<a id="attitude-commands"></a>
## 姿态角环与角速度环调参指令

通用格式：`命令字符 + 参数编号 = 数值 + !`。

有效调参值成功写入后，主板 `P19_4` 蜂鸣器会短响两声作为确认。查询命令、波形切换、急停命令以及参数编号无效的写入不会触发提示音；提示音由 5 ms 周期任务非阻塞播放，不会暂停控制任务或 VOFA 收发。

| 命令 | 控制器 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| R | Roll 角度环 | Kp | Ki | Kd | - |
| P | Pitch 角度环 | Kp | Ki | Kd | - |
| Y | Yaw 角度环 | Kp | Ki | Kd | - |
| r | Roll 角速度环 | Kp | Ki | Kd | 积分限幅 |
| p | Pitch 角速度环 | Kp | Ki | Kd | 积分限幅 |
| y | Yaw 角速度环 | Kp | Ki | Kd | 积分限幅 |

示例：

```text
R1=2.5!
p3=0.4!
r4=100!
```

发送不带数值的命令可以读取当前参数，例如 `R0!`、`p0!`。

<a id="velocity-commands"></a>
## 速度环调参指令

| 命令 | 控制器 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| V | X/前向速度环 | Kp | Ki | Kd | 输出限幅（deg） | 积分限幅 | Pitch 前馈增益 | Pitch 前馈限幅（deg/s） | D低通（Hz） |
| W | Y/左向速度环 | Kp | Ki | Kd | 输出限幅（deg） | 积分限幅 | Roll 前馈增益 | Roll 前馈限幅（deg/s） | D低通（Hz） |

速度 PID 输出直接作为 Pitch/Roll 修正角。目标角变化率前馈在角度 PID 之后叠加到目标角速度，不会增大目标角。D低通合法范围为`1～50 Hz`，默认`8 Hz`，通过`V8=8!`和`W8=8!`直接按Hz设置，不需要换算alpha。`V!`和`W!`参数查询的I7返回当前D截止频率。前馈示例：`V6=0.2!`、`W6=0.2!`、`V7=60!`、`W7=60!`。

## 油门、悬停角与光流去旋转

| 命令 | 含义 |
| --- | --- |
| `S0=数值!` | 设置目标油门 |
| `B1=数值!` | 设置悬停 Roll 补偿角 |

<a id="tuning-order"></a>
## 飞行调参建议顺序

1. `F3`：确认通信链路连续。
2. `F4`：确认 IMU 轴向、静止噪声和校准状态。
3. `FZ`：确认电池电压、补偿增益和电机输出没有饱和。
4. `FY`：确认控制任务没有持续超期。
5. `F5/F7/F9`：分别调 Roll、Pitch、Yaw 角速度内环，并检查 PID 分项与电机输出饱和。
6. `F6`：角速度内环稳定后，再调姿态外环。
7. `FD`：调高度位置环与垂直速度环。
8. `FU`：确认光流和融合速度方向、尺度、置信度。
9. `F8`：调水平速度环。
10. `FI`：地面确认视觉位置方向后，再从很小的 Kp 开始调位置环。
11. `F2`：最后用全局总览检查各层闭环协同。

每次只改变一个参数，并记录修改前数值、修改后数值、电池电压和对应波形。自动位置闭环第一次测试应限制高度、速度和姿态修正量，并确保可以立即发送 `00!` 或使用机身急停操作。
