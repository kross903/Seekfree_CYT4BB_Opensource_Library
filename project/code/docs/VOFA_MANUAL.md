## 连接与命令格式

| 项目 | 当前配置 |
| --- | --- |
| 串口 | UART1 |
| 波特率 | 115200 |
| 数据协议 | VOFA+ JustFloat |
| 帧尾 | `00 00 80 7F` |
| 波形通道 | 8 路或 16 路 float |
| 命令结束符 | `!` |

所有命令必须以 `!` 结尾，例如：

```text
F6!
R1=2.5!
00!
```

拨码 `P09_0` 和 `P09_1` 同时为低电平时，UART1 被切换到逐飞助手图像模式，此时 VOFA 收发停止。调参时应保证没有同时进入图像模式。

发送某个 `F` 指令后，固件会持续发送该模式，直到收到另一个有效的 `F` 指令。通道编号按 VOFA 中的 `I0`、`I1`……排列。

<a id="f2"></a>
## F2：全局飞行总览

用途：起飞和综合联调时统一观察姿态、高度、速度与位置。该页面用于快速判断问题属于哪一层，不适合代替各闭环专用页面做精调。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | Roll 目标角 | deg |
| I1 | Roll 反馈角 | deg |
| I2 | Pitch 目标角 | deg |
| I3 | Pitch 反馈角 | deg |
| I4 | Yaw 目标角 | deg |
| I5 | Yaw 反馈角 | deg |
| I6 | 高度目标 | cm |
| I7 | 高度反馈 | cm |
| I8 | X 轴目标速度 | cm/s |
| I9 | X 轴融合反馈速度 | cm/s |
| I10 | Y 轴目标速度 | cm/s |
| I11 | Y 轴融合反馈速度 | cm/s |
| I12 | X 轴位置目标 | cm |
| I13 | X 轴视觉位置反馈 | cm |
| I14 | Y 轴位置目标 | cm |
| I15 | Y 轴视觉位置反馈 | cm |

重点观察：目标与反馈方向是否一致、起飞后是否出现某一层明显发散。

<a id="f3"></a>
## F3：VOFA 通信测试

用途：不依赖传感器验证 UART、无线链路和 JustFloat 解码。

| 通道 | 数据 |
| --- | --- |
| I0 | 在 0 到 100 之间往返变化的三角波 |
| I1-I7 | 0 |

如果 I0 不连续、停顿或跳变，先处理通信问题，不要直接判断控制环有故障。

<a id="f4"></a>
## F4：IMU 原始量与处理量

用途：检查 IMU 轴向、量程转换、静止噪声、加速度模值和校准状态。

| 通道 | 数据 |
| --- | --- |
| I0-I2 | 陀螺仪 X/Y/Z 原始值 |
| I3-I5 | 陀螺仪 X/Y/Z 转换值 |
| I6-I8 | 加速度计 X/Y/Z 原始值 |
| I9-I11 | 加速度计 X/Y/Z 转换值 |
| I12 | `acc` 加速度模值 |
| I13 | 姿态解算使用的滤波后加速度模值 |
| I14 | IMU 数据质量检查结果 |
| I15 | IMU 校准运行标志 |

静止检查时应重点观察 I3-I5 是否接近零、I13 是否稳定，以及 I14/I15 是否表明传感器可用。

| I1 | Roll 反馈角 | deg |
| I2 | Roll 目标角速度 | deg/s |
| I3 | Roll 陀螺反馈 | deg/s |
| I4 | Roll 控制输出 | 内部输出量 |
| I5 | Pitch 目标角 | deg |
| I6 | Pitch 反馈角 | deg |
| I7 | Pitch 目标角速度 | deg/s |
| I8 | Pitch 陀螺反馈 | deg/s |
| I9 | Pitch 控制输出 | 内部输出量 |
| I10 | Yaw 目标角 | deg |
| I11 | Yaw 反馈角 | deg |
| I12 | Yaw 目标角速度 | deg/s |
| I13 | Yaw 陀螺反馈 | deg/s |
| I14 | Yaw 控制输出 | 内部输出量 |
| I15 | 基础油门 | 0-2000 |

先观察目标角速度与陀螺反馈，再观察目标角与姿态反馈。内环没有稳定前不要继续提高外环增益。

<a id="f8"></a>
## F8：水平速度闭环

用途：检查光流融合速度到姿态修正角的速度环。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | X 轴目标速度 | cm/s |
| I1 | X 轴融合反馈速度 | cm/s |
| I2 | X 轴积分输出 | cm/s² |
| I3 | Pitch 修正角 | deg |
| I4 | Y 轴目标速度 | cm/s |
| I5 | Y 轴融合反馈速度 | cm/s |
| I6 | Y 轴积分输出 | cm/s² |
| I7 | Roll 修正角 | deg |

X 轴速度通过 Pitch 修正，Y 轴速度通过 Roll 修正。调参前必须先确认推动机体时反馈速度符号正确。

<a id="fa"></a>
## FA：水平加速度与惯导速度

用途：检查机体系加速度转到水平坐标后的零偏，以及纯惯导速度漂移趋势。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | 水平坐标 X 加速度 | mg |
| I1 | 水平坐标 Y 加速度 | mg |
| I2 | X 加速度水平零偏 | mg |
| I3 | Y 加速度水平零偏 | mg |
| I4 | X 去零偏加速度 | mg |
| I5 | Y 去零偏加速度 | mg |
| I6 | X 滤波后线速度 `X_V_F` | 工程速度单位 |
| I7 | Y 滤波后线速度 `Y_V_F` | 工程速度单位 |

机体静止且水平时，I4/I5 应围绕零小幅波动；I6/I7 长时间明显单向漂移说明加速度零偏仍需处理。

## FY：控制实时性

用途：确认 4 kHz 控制任务、2 kHz 电机输出和主循环没有超期。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | 控制任务最近耗时 | us |
| I1 | 控制任务历史最大耗时 | us |
| I2 | 控制任务最小进入间隔 | us |
| I3 | 控制任务最大进入间隔 | us |
| I4 | 控制任务执行超期次数 | 次 |
| I5 | 控制任务延迟进入次数 | 次 |
| I6 | 控制任务执行总次数 | 次 |
| I7 | 电机任务最近耗时 | us |
| I8 | 电机任务历史最大耗时 | us |
| I9 | 电机任务执行超期次数 | 次 |
| I10 | 电机任务执行总次数 | 次 |
| I11 | VOFA 主循环最近耗时 | us |
| I12 | VOFA 主循环历史最大耗时 | us |
| I13 | VOFA 主循环滑动平均耗时 | us |
| I14 | VOFA 主循环超期次数 | 次 |
| I15 | VOFA 主循环执行总次数 | 次 |

控制周期是 250 us，电机输出周期是 500 us。重点看 I1 是否接近 250、I3 是否明显大于 250，以及 I4/I5 是否持续增长。

<a id="fz"></a>
## FZ：电池、电压补偿与电机串口

用途：检查 4S 电池采样、电压补偿、电机输出饱和和小驱板串口状态。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | 本机原始电池电压 | V |
| I1 | 本机滤波电池电压 | V |
| I2 | 远端电池电压 | V |
| I3 | 电压补偿增益 | 倍率 |
| I4 | 本机电压有效标志 | 0/1 |
| I5 | 远端电压有效标志 | 0/1 |
| I6 | 低电压警告 | 0/1 |
| I7-I10 | 电机 1-4 补偿后输出 | 0-2000 |
| I11 | 电机输出饱和位掩码 | bit0-bit3 |
| I12 | 电机补偿非法输出标志 | 0/1 |
| I13 | 小驱板待发帧被覆盖次数 | 次 |
| I14 | 小驱板待发最大延迟 | us |
| I15 | 小驱板软件 FIFO 错误次数 | 次 |

当前 4S 配置以 15.2 V 为补偿参考，增益限制为 0.90-1.15。低压警告阈值是 14.8 V，恢复阈值是 15.2 V。

飞机本机电压使用 E1 母板官方检测通道 `P07_5 / ADC0_CH21`，12 位 ADC 按 `36.3 / 4096` 换算。Flight View 的 `BAT` 与 FZ 的 I1 都显示该本机滤波电压；FZ 的 I4 为 1 后，电压补偿才会启用。

<a id="attitude-commands"></a>
## 姿态角环与角速度环调参指令

通用格式：`命令字符 + 参数编号 = 数值 + !`。

| 命令 | 控制器 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| R | Roll 角度环 | Kp | Ki | Kd | - |
| P | Pitch 角度环 | Kp | Ki | Kd | - |
| Y | Yaw 角度环 | Kp | Ki | Kd | - |
| r | Roll 角速度环 | Kp | Ki | Kd | 积分限幅 |
| p | Pitch 角速度环 | Kp | Ki | Kd | 积分限幅 |
| y | Yaw 角速度环 | Kp | Ki | Kd | 积分限幅 |

示例：

```text
R1=2.5!
p3=0.4!
r4=100!
```

发送不带数值的命令可以读取当前参数，例如 `R0!`、`p0!`。

## 速度环调参指令

| 命令 | 控制器 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| V | X/前向速度环 | Kp | Ki | Kd | 输出限幅 | 积分限幅 |
| W | Y/左向速度环 | Kp | Ki | Kd | 输出限幅 | 积分限幅 |

速度环输出是水平加速度指令，随后换算成 Pitch/Roll 修正角。

<a id="position-commands"></a>
## 位置环调参指令

| 命令 | 控制器 | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| I | X 位置环 | 启用/关闭位置环 | Kp | Ki | Kd | 输出限幅 | 积分限幅 |
| J | Y 位置环 | 启用/关闭位置环 | Kp | Ki | Kd | 输出限幅 | 积分限幅 |

`I0=1!` 或 `J0=1!` 会启用整个位置环，`I0=0!` 或 `J0=0!` 会关闭。上机前先保持关闭，完成视觉方向验证后再启用。

<a id="other-commands"></a>
## 油门、悬停角与光流去旋转

| 命令 | 含义 |
| --- | --- |
| `S0=数值!` | 设置目标油门 |
| `B1=数值!` | 设置悬停 Roll 补偿角 |
| `B2=数值!` | 设置悬停 Pitch 补偿角 |
| `Gx=数值!` | 设置光流 X 去旋转增益 |
| `Gy=数值!` | 设置光流 Y 去旋转增益 |
| `00!` | 立即撤销解锁并将控制油门归零 |

调参命令修改的是 RAM 中的当前运行参数。是否掉电保存取决于对应参数是否另行写入 Flash，不要默认认为 VOFA 修改会永久保存。

<a id="tuning-order"></a>
## 飞行调参建议顺序

1. `F3`：确认通信链路连续。
2. `F4`：确认 IMU 轴向、静止噪声和校准状态。
3. `FZ`：确认电池电压、补偿增益和电机输出没有饱和。
4. `FY`：确认控制任务没有持续超期。
5. `F6`：先调角速度内环，再调姿态外环。
6. `FD`：调高度位置环与垂直速度环。
7. `FU`：确认光流和融合速度方向、尺度、置信度。
8. `F8`：调水平速度环。
9. `FI`：地面确认视觉位置方向后，再从很小的 Kp 开始调位置环。
10. `F2`：最后用全局总览检查各层闭环协同。

每次只改变一个参数，并记录修改前数值、修改后数值、电池电压和对应波形。自动位置闭环第一次测试应限制高度、速度和姿态修正量，并确保可以立即发送 `00!` 或使用机身急停操作。
