## 连接与命令格式

| 项目 | 当前配置 |
| --- | --- |
| 串口 | UART1 |
| 波特率 | 115200 |
| 数据协议 | VOFA+ JustFloat |
| 帧尾 | `00 00 80 7F` |
| 波形通道 | 8 路或 16 路 float |
| 命令结束符 | `!` |

所有命令必须以 `!` 结尾，例如：

```text
F6!
R1=2.5!
00!
```

拨码 `P09_0` 和 `P09_1` 同时为低电平时，UART1 被切换到逐飞助手图像模式，此时 VOFA 收发停止。调参时应保证没有同时进入图像模式。

发送某个 `F` 指令后，固件会持续发送该模式，直到收到另一个有效的 `F` 指令。通道编号按 VOFA 中的 `I0`、`I1`……排列。

## F2：全局飞行总览

用途：起飞和综合联调时统一观察姿态、高度、速度与位置。该页面用于快速判断问题属于哪一层，不适合代替各闭环专用页面做精调。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | Roll 目标角 | deg |
| I1 | Roll 反馈角 | deg |
| I2 | Pitch 目标角 | deg |
| I3 | Pitch 反馈角 | deg |
| I4 | X 轴目标角速度（Roll） | deg/s |
| I5 | X 轴实际角速度（Roll） | deg/s |
| I6 | Y 轴目标角速度（Pitch） | deg/s |
| I7 | Y 轴实际角速度（Pitch） | deg/s |
| I8 | X 轴目标速度 | cm/s |
| I9 | X 轴融合反馈速度 | cm/s |
| I10 | Y 轴目标速度 | cm/s |
| I11 | Y 轴融合反馈速度 | cm/s |
| I12 | X 轴位置误差 | cm |
| I13 | Y 轴位置误差 | cm |
| I14 | F2 帧序号，达到 1000000 后归零 | 帧 |
| I15 | 相邻 F2 帧发送间隔 | ms |

重点观察：目标与反馈方向是否一致、起飞后是否出现某一层明显发散。I14 正常应逐帧加 1，跳号表示接收端漏帧；I15 第一帧为 0，之后反映飞控端相邻两次 F2 发送之间的时间。

角度模式 KEY3 缓启动顺序为：1 秒零输出、1.2 秒四电机等值软起转到 300、0.5 秒 300 怠速保持、3 秒姿态闭环渐升到 750，最后在 3 秒内把高度目标从当前高度平滑升到 110 cm。前三个阶段不运行姿态 PID，`HEIGHT BLEND` 之前高度 PID 输出始终为 0。Flight View 会显示当前阶段；任意按键仍立即急停。

起飞前和缓启动期间不再使用 ToF 有效状态拒绝解锁或触发急停。正常飞行中仍持续判断 ToF；无效时高度 PID 输出清零并复位，基础油门和姿态环继续运行。

通过实体按键急停后，飞控强制保持 2 秒重新解锁禁止期。期间 Flight View 显示 `ESTOP LOCK - WAIT 2S`，重复按 KEY3 不会清除急停锁存；2 秒结束后再次按 KEY3 才能重新执行安全检查和缓启动。

Flight View 内置起飞诊断区：进入任一起飞阶段后显示绿色 `STARTING`、当前阶段和阶段进度；KEY3 请求被拒绝或起飞状态机中途退出后显示红色 `STOP`，并以 6×8 小字体显示停止原因、源文件 basename、代码行号和被中止时的状态。诊断区使用屏幕 `y=224-287`，底部两行提示仍位于 `y=288/304`，不会超过 IPS200 竖屏 320 像素高度。

## F3：VOFA 通信测试

用途：不依赖传感器验证 UART、无线链路和 JustFloat 解码。

| 通道 | 数据 |
| --- | --- |
| I0 | 在 0 到 100 之间往返变化的三角波 |
| I1-I7 | 0 |

如果 I0 不连续、停顿或跳变，先处理通信问题，不要直接判断控制环有故障。

## F4：IMU 原始量与处理量

用途：检查 IMU 轴向、量程转换、静止噪声、加速度模值和校准状态。

| 通道 | 数据 |
| --- | --- |
| I0-I2 | 陀螺仪 X/Y/Z 原始值 |
| I3-I5 | 陀螺仪 X/Y/Z 转换值 |
| I6-I8 | 加速度计 X/Y/Z 原始值 |
| I9-I11 | 加速度计 X/Y/Z 转换值 |
| I12 | `acc` 加速度模值 |
| I13 | 姿态解算使用的滤波后加速度模值 |
| I14 | IMU 健康故障位掩码，0 表示当前无故障 |
| I15 | 姿态有效标志：0 无效、1 有效 |

静止时应重点观察 I3-I5 是否接近零、I13 是否稳定。I14 的 bit0-bit4 依次表示非有限数、加速度模值异常、陀螺饱和、四元数异常和样本停更；无故障时 I14 为 0、I15 为 1。bit1（I14=2）出现时，Mahony 会把加速度修正权重降到最低，姿态主要由陀螺积分。飞行中 I14/I15 仅用于诊断和 Flight View 提示，不再直接触发急停；解锁时仍通过完整 IMU 健康检查决定是否允许启动。

Flight View 触发 `INVALID CTRL` 时会进一步显示具体原因：`ATTITUDE NAN/INF`、`GYRO NAN/INF`、`BASE THROTTLE NAN` 或 `MIXER OUTPUT NAN`。IMU 健康位本身不再触发飞行中急停。

## F5/F7/F9：三轴角速度环分项

用途：分别观察 Roll、Pitch、Yaw 角速度环的目标、反馈、PID 分项、输出限幅和四电机混控结果。使用 `F5!` 观察 Roll，使用 `F7!` 观察 Pitch，使用 `F9!` 观察 Yaw。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | 目标角速度 | deg/s |
| I1 | 实际角速度 | deg/s |
| I2 | 角速度误差：目标 - 实际 | deg/s |
| I3 | P 项输出 | 内部输出量 |
| I4 | I 项输出 | 内部输出量 |
| I5 | D 项输出 | 内部输出量 |
| I6 | 限幅前 P+I+D 总和 | 内部输出量 |
| I7 | 限幅后、实际进入混控的总输出 | 内部输出量 |
| I8 | 输出饱和标志 | 0/1 |
| I9 | 目标姿态角 | deg |
| I10 | 实际姿态角 | deg |
| I11 | 基础油门 | 0-2000 |
| I12-I15 | 电机 1-4 混控并限幅后的油门 | 0-2000 |

无饱和时 I3+I4+I5 应等于 I6，I6 应等于 I7；发生输出限幅时 I8 为 1，I7 保持在角速度环输出限幅内。Yaw 为匹配实际混控方向，I3-I7 已统一反号，因此仍满足分项相加关系，但 P 项符号与 `Kp × I2` 相反。

## F6：姿态角环与角速度环

用途：姿态内外环的主要调参页面。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | Roll 目标角 | deg |
| I1 | Roll 反馈角 | deg |
| I2 | Roll 目标角速度 | deg/s |
| I3 | Roll 陀螺反馈 | deg/s |
| I4 | Roll 控制输出 | 内部输出量 |
| I5 | Pitch 目标角 | deg |
| I6 | Pitch 反馈角 | deg |
| I7 | Pitch 目标角速度 | deg/s |
| I8 | Pitch 陀螺反馈 | deg/s |
| I9 | Pitch 控制输出 | 内部输出量 |
| I10 | Yaw 目标角 | deg |
| I11 | Yaw 反馈角 | deg |
| I12 | Yaw 目标角速度 | deg/s |
| I13 | Yaw 陀螺反馈 | deg/s |
| I14 | Yaw 控制输出 | 内部输出量 |
| I15 | Yaw 最短角误差，范围 `[-180, 180)` | deg |

Yaw 外环使用 `wrap180(目标角-反馈角)`，因此反馈跨越 `+180°/-180°` 时 I15 应连续，例如目标 `179°`、反馈 `-179°` 时 I15 应为 `-2°`，不能出现 `358°`。先观察目标角速度与陀螺反馈，再观察目标角与姿态反馈；内环没有稳定前不要继续提高外环增益。飞行中 Yaw 陀螺反馈绝对值连续超过 `200°/s` 达 `150 ms` 会触发 `ESTOP YAW SPIN`，并锁定重新起飞 `2 s`。

用途：检查机体系加速度转到水平坐标后的零偏，以及纯惯导速度漂移趋势。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | 水平坐标 X 加速度 | mg |
| I1 | 水平坐标 Y 加速度 | mg |
| I2 | X 加速度水平零偏 | mg |
| I3 | Y 加速度水平零偏 | mg |
| I4 | X 去零偏加速度 | mg |
| I5 | Y 去零偏加速度 | mg |
| I6 | X 滤波后线速度 `X_V_F` | 工程速度单位 |

用途：采集安装矩阵求解需要的六面原始加速度。拆除桨叶后使用；每次摆好一个姿态，发送 `FC!` 并单独导出一份 CSV。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | 加速度计传感器 X 原始值 | count |
| I1 | 加速度计传感器 Y 原始值 | count |
| I2 | 加速度计传感器 Z 原始值 | count |
| I3 | 原始加速度模值 | count |
| I4 | 当前矩阵转换后的机体 X 加速度 | mg |
| I5 | 当前矩阵转换后的机体 Y 加速度 | mg |
| I6 | 当前矩阵转换后的机体 Z 加速度 | mg |
| I7 | 姿态解算使用的滤波后加速度模值 | mg |
| I8 | 当前矩阵转换后的机体 X 角速度 | deg/s |
| I9 | 当前矩阵转换后的机体 Y 角速度 | deg/s |
| I10 | 当前矩阵转换后的机体 Z 角速度 | deg/s |
| I11 | 当前样本是否满足基本静止条件 | 0/1 |
| I12 | IMU 健康故障位掩码 | bitmask |
| I13 | IMU 样本序号 | 帧 |
| I14 | FC 发送帧序号，达到 1000000 后归零 | 帧 |
| I15 | 相邻 FC 帧发送间隔 | ms |

矩阵脚本默认读取 `I0/I1/I2`，并在 CSV 中存在 `I11` 时自动只保留 `I11=1` 的静止行。每个姿态建议连续记录 5-10 秒；开始和结束搬动飞机时可以保持记录，脚本会自动剔除这些行。六份文件仍需由操作者明确标记为 `px/nx/py/ny/pz/nz`，飞控不会根据当前矩阵自动猜测机体朝向。

<a id="fd"></a>
## FD：ToF 跳变拒绝与重捕获

用途：检查 ToF 原始距离、姿态补偿、动态创新门、候选重捕获和失效超时。高度环的最终反馈仍是 I3。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | 最新原始 LOS 距离 | cm |
| I1 | 姿态与安装补偿后的机体中心高度 | cm |
| I2 | 三点中值滤波高度 | cm |
| I3 | 最终低通高度 | cm |
| I4 | 根据上次可信补偿高度和垂直速度得到的预测高度 | cm |
| I5 | 创新量：I1 - I4 | cm |
| I6 | 当前动态创新门 | cm |
| I7 | 门外候选高度均值 | cm |
| I8 | 当前连续一致候选数 | 帧 |
| I9 | 自上次正常接受后累计的门外帧数 | 帧 |
| I10 | ToF 跟踪状态 | 枚举值 |
| I11 | 最近有效范围帧年龄 | ms |
| I12 | 最近可信高度年龄 | ms |
| I13 | ToF 垂直速度 | cm/s |
| I14 | ToF 原始帧序号，达到 1000000 后归零 | 帧 |
| I15 | ToF 可信轨迹有效标志 | 0/1 |

I10 状态定义：`0=INVALID`、`1=LIVE`、`2=HELD_REJECTED`、`3=REACQUIRING`。光流与高度环统一读取这套状态；状态 2/3 时光流使用最后可信高度并降低置信度，状态 0 时停止使用 ToF 距离尺度。

有效原始距离为 `2～200 cm`。正常测量需要满足动态门 `5 cm + 100 cm/s × 最近可信高度年龄`，动态门最大为 `20 cm`。进入候选状态后暂时冻结首次拒绝时的门限，防止门限随保持时间增大而提前接受同一跳变；测量回到原可信轨迹后仍可立即恢复 LIVE。门外测量不会进入中值、低通和速度差分；候选与候选均值相差不超过 `10 cm` 时累计，连续 5 帧一致后重捕获。累计 10 个门外帧仍无法形成稳定候选时，I15 置 0。

轮询暂时没有新帧时保留上一可信高度；连续 `100 ms` 没有有效范围帧才失效。首个有效帧直接初始化，初始化前高度为 0 且 I15 为 0，不再显示虚假的 100 cm 初始高度。

| I5 | ToF1 有效缓存标志 | 0/1 |
| I6 | ToF2 有效缓存标志 | 0/1 |
| I7 | ToF1 最近有效帧年龄 | ms |
| I8 | ToF2 最近有效帧年龄 | ms |
| I9 | HeightManager 当前原始输入 | cm |

| I12 | 统一 ToF 可信标志 | 0/1 |
| I13 | ToF1 无效帧累计数 | 次 |
| I14 | ToF2 无效帧累计数 | 次 |
| I15 | ToF2 总线/初始化错误累计数 | 次 |

两路都有效时 I2 取较大值；一路有效时取另一路；两路都无效时不生成新样本，继续使用原有 ToF 超时逻辑。I3 只用于诊断，不会阻止大值输出。两路缓存超过约 `100 ms` 未更新后分别失效。

## FE：电调故障与遥测状态

用途：检查四合一电调上报的最新故障事件、当前活动故障和状态帧通信质量。发送 `FE!` 或 `Fe!` 后立即输出首帧，随后固定以 `20 Hz` 发送。

| 通道 | 数据 | 单位 |
| --- | --- | --- |
| I0 | 电调状态帧有效标志 | 0/1 |
| I1 | 电调遥测超时 `STALE` 标志 | 0/1 |
| I2 | 最近状态帧年龄 | ms |
| I3 | 电调状态协议版本 | 版本号 |
| I4 | 已接收状态帧总数 | 帧 |
| I5 | 状态帧校验错误总数 | 帧 |
| I6 | 未知功能字或版本帧总数 | 帧 |
| I7 | 去重后的故障事件累计数 | 次 |
| I8 | 最近故障事件 `SEQ` | 0-255 |
| I9 | 最近故障码 | 枚举值 |
| I10 | 最近故障电机掩码 | bitmask |
| I11 | 当前活动故障电机掩码 | bitmask |
| I12 | M1 当前活动故障码 | 枚举值 |
| I13 | M2 当前活动故障码 | 枚举值 |
| I14 | M3 当前活动故障码 | 枚举值 |
| I15 | M4 当前活动故障码 | 枚举值 |

I9 和 I12-I15 的故障码定义：`0=无故障`、`1=电压异常`、`2=堵转`、`3=干扰/失步`、`4=启动失败`、`5=温度过低`、`6=温度过高`、`7=母线过流`、`8=低速退出闭环并重启`。I10/I11 的 bit0-bit3 依次对应 M1-M4，例如数值 `5` 表示 M1 和 M3。

I8-I10 锁存最近一次唯一故障，正常 `CODE=0` 心跳不会清除，直到下一次故障覆盖或飞控重启。I11-I15 是当前活动状态，只有在 `I0=1` 且 `I1=0` 时视为实时可信。同一 `SEQ` 的两次重复状态帧只会使 I7 增加一次。电调故障当前只上报和显示，不会触发飞控急停；活动故障未清除时仍拒绝下一次解锁。

<a id="attitude-commands"></a>
## 姿态角环与角速度环调参指令

通用格式：`命令字符 + 参数编号 = 数值 + !`。

有效调参值成功写入后，主板 `P19_4` 蜂鸣器会短响两声作为确认。查询命令、波形切换、急停命令以及参数编号无效的写入不会触发提示音；提示音由 5 ms 周期任务非阻塞播放，不会暂停控制任务或 VOFA 收发。

| 命令 | 控制器 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| R | Roll 角度环 | Kp | Ki | Kd | - |
| P | Pitch 角度环 | Kp | Ki | Kd | - |
| Y | Yaw 角度环 | Kp | Ki | Kd | - |
| r | Roll 角速度环 | Kp | Ki | Kd | 积分限幅 |
| p | Pitch 角速度环 | Kp | Ki | Kd | 积分限幅 |
| y | Yaw 角速度环 | Kp | Ki | Kd | 积分限幅 |

示例：

```text
R1=2.5!
p3=0.4!
r4=100!
```

发送不带数值的命令可以读取当前参数，例如 `R0!`、`p0!`。

<a id="tuning-order"></a>
## 飞行调参建议顺序

1. `F3`：确认通信链路连续。
2. `F4`：确认 IMU 轴向、静止噪声和校准状态。
3. `FZ`：确认电池电压、补偿增益和电机输出没有饱和。
4. `FY`：确认控制任务没有持续超期。
5. `F5/F7/F9`：分别调 Roll、Pitch、Yaw 角速度内环，并检查 PID 分项与电机输出饱和。
6. `F6`：角速度内环稳定后，再调姿态外环。
7. `FD`：调高度位置环与垂直速度环。
8. `FU`：确认光流和融合速度方向、尺度、置信度。
9. `F8`：调水平速度环。
10. `FI`：地面确认视觉位置方向后，再从很小的 Kp 开始调位置环。
11. `F2`：最后用全局总览检查各层闭环协同。

每次只改变一个参数，并记录修改前数值、修改后数值、电池电压和对应波形。自动位置闭环第一次测试应限制高度、速度和姿态修正量，并确保可以立即发送 `00!` 或使用机身急停操作。
