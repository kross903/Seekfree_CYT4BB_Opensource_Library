## 1. 按键定义

物理按键与菜单按键编号的对应关系:

- `KEY_1` -> `Button_1`
- `KEY_2` -> `Button_2`
- `KEY_3` -> `Button_3`
- `KEY_4` -> `Button_4`

在主菜单和普通列表页中:

- `KEY_1`: 上移
- `KEY_2`: 下移
- `KEY_3`: 确定
- `KEY_4`: 返回

---

## 2. 一级菜单

开机后进入主菜单 `Main Menu`，当前一级菜单共有 4 项:

1. `Parameters`
2. `Schemes`
3. `ICM Init`
4. `Flight View`

---

## 3. 一级菜单详细说明

### 3.1 Parameters

功能:

- 进入参数浏览和编辑页面
- 会先加载参数，再进入参数配置界面

页面内有两种状态:

#### 浏览状态

- `KEY_1`: 上一个参数
- `KEY_2`: 下一个参数
- `KEY_3`: 进入编辑
- `KEY_4`: 返回主菜单

屏幕提示通常为:

- `1:Up 2:Down 3:Edit 4:Menu`

#### 编辑状态

- `KEY_1`: 增大当前参数
- `KEY_2`: 减小当前参数
- `KEY_3`: 保存当前参数，并写入 Flash
- `KEY_4`: 取消本次编辑，恢复该参数原值

屏幕提示通常为:

- `1:+ 2:- 3:Save 4:Cancel`

补充说明:

- 退出 `Parameters` 页面后会自动回到主菜单
- 如果有参数改动，页面会短暂提示 `Parameters Saved!`

---

### 3.2 Schemes

功能:

- 进入参数方案管理页面

`Schemes` 页面内部有自己的二级菜单，共 6 项:

1. `Save Current Scheme`
2. `Delete Scheme`
3. `Load Scheme`
4. `View Scheme Details`
5. `Backup to W25N04`
6. `Restore from W25N04`

在 `Schemes` 主页面中:

- `KEY_1`: 上移
- `KEY_2`: 下移
- `KEY_3`: 确定
- `KEY_4`: 返回主菜单

各项功能说明如下:

#### Save Current Scheme

- 进入保存确认框
- `KEY_3`: 确认保存
- `KEY_4`: 取消

#### Delete Scheme

- 进入方案列表
- `KEY_1` / `KEY_2`: 选择方案
- `KEY_3`: 删除当前方案
- `KEY_4`: 返回上一级

删除前会进入确认框:

- `KEY_3`: 确认删除
- `KEY_4`: 取消

#### Load Scheme

- 进入方案列表
- `KEY_1` / `KEY_2`: 选择方案
- `KEY_3`: 加载当前方案，并保存到参数
- `KEY_4`: 返回

#### View Scheme Details

- 进入方案列表
- `KEY_1` / `KEY_2`: 选择方案
- `KEY_3`: 查看方案详情
- `KEY_4`: 返回

在详情页中:

- `KEY_1`: 向上滚动
- `KEY_2`: 向下滚动
- `KEY_4`: 返回方案列表

#### Backup to W25N04

- 进入确认框
- `KEY_3`: 确认备份
- `KEY_4`: 取消

#### Restore from W25N04

- 进入确认框
- `KEY_3`: 确认恢复
- `KEY_4`: 取消

---

### 3.3 ICM Init

功能:

- 执行一次 `ICM_Calculate_Init()`

说明:

- 该项不是二级菜单
- 按 `KEY_3` 后直接执行
- 执行完成后自动返回主菜单

---

### 3.4 Flight View

功能:

- 进入飞行监视页

进入前会先显示确认页，页面内容类似:

- `SELECT CTRL MODE`
- `0. MANUAL`
- `1. ANGLE`

在确认页中:

- `KEY_1` / `KEY_2`: 切换 `MANUAL` 和 `ANGLE`
- `KEY_3`: 保存模式并进入监视页
- `KEY_4`: 取消并回主菜单

两种模式含义:

- `MANUAL`: 手动油门直通模式，只把基础油门直接铺到 4 个电机，不参与姿态闭环
- `ANGLE`: 姿态稳定模式，走姿态角外环 + 角速度内环

确认后会播放一个退出动画，然后进入飞行监视页。

---

## 4. 什么是飞行监视页

飞行监视页不是菜单页，而是运行状态显示页。

当前监视页会显示和刷新这些内容:

- 相机灰度图
- 红外定位处理结果
- 信标检测结果 `BCN`
- 最近信标的 `X / Y`
- 目标角度相关数据显示
- `target_throttle`
- `aa`
- `armed`
- 低压提示信息

它的作用可以理解成:

- 一边看图像和识别结果
- 一边看飞行相关状态量
- 一边继续接受按键和 VOFA 调试输入

---

## 5. 飞行监视页按键

飞行监视页里的按键逻辑和菜单页不同:

- `KEY_1`: 增加油门
- `KEY_2`: 减少油门
- `KEY_3`: 执行原点标定，并置 `armed = 1`
- `KEY_4`: 触发人工急停

补充说明:

- 在飞行监视页中，`KEY_4` 按下后会立即走统一急停接口
- 急停会同时清掉解锁状态、油门状态和电机输出缓存
- 在飞行监视页中，`KEY_4` 不是立刻返回菜单
- 需要持续按一段时间，才会返回主菜单
- 当前代码条件是 `key_tick > 50`

可以把它理解成:

- 短按 `KEY_4` 主要是停机
- 长按 `KEY_4` 才是“退出监视页，回主菜单”

## 6. 安全保护说明

补充时间: 2026-03-10

当前代码里已经接入的两种主要急停来源:

1. 人工急停

- 位置: 飞行监视页
- 触发方式: 按下 `KEY_4`
- 当前行为: 立即触发统一急停

2. 姿态超限自动急停

- 触发条件:
  - `roll` 超过 `±20°`
  - `pitch` 超过 `±20°`
- 当前行为: 主控制 ISR 内立即触发统一急停

补充说明:

- 这两种急停现在已经统一走同一个停机接口
- 旧的红外预留急停注释逻辑已经删除，不再作为当前有效保护的一部分理解

## 7. 实际使用顺序建议

建议按下面顺序使用:

1. 开机后进入 `Main Menu`
2. 用 `KEY_1` / `KEY_2` 选择菜单项
3. 用 `KEY_3` 进入对应页面
4. 如果要调参数，进入 `Parameters`
5. 如果要管理参数方案，进入 `Schemes`
6. 如果要重新做 ICM 初始化，进入 `ICM Init`
7. 如果要看图像和飞行状态，进入 `Flight View`
8. 在飞行监视页中长按 `KEY_4` 回主菜单

## 10. 2026-03-10 补充: Flight View 监视页更新

补充时间: 2026-03-10

本次更新后，`Flight View` 的监视页有 3 个变化:

1. 屏幕排版改成固定分区

- 上半部分: 相机灰度图
- 下半部分: 模式、解锁状态、电池电压、油门、姿态、信标、ToF/融合高度数据
- 低压提示不再单独叠加到图像上，因此不会再把图像和文字堆在一起

2. 监视页按键逻辑改成直接读取底层按键状态

- `KEY_1`: 短按，目标油门 `+50`
- `KEY_2`: 短按，目标油门 `-50`
- `KEY_3`: 短按，执行原点标定，然后重新解锁，并把目标油门设为 `100`
- `KEY_4`: 短按，人工急停
- `KEY_4`: 长按，返回主菜单

3. 电池显示方式改成固定 HUD

- `BAT`: 当前缓存电压值
- `STAT`: `OK` / `LOW`
- 如果后续发现显示电压和万用表仍有偏差，优先去校准 `BATTERY_ADC_TO_VOLTAGE_SCALE`
