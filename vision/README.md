# 视觉代码仿真上位机

这是一个电脑端 Tkinter 工具，用真实的固件视觉 C 源码处理 `188x120` 灰度帧。

## 启动

```powershell
python vision_tool.py
```

首次启动前需要安装 GCC/Clang。Windows 推荐 MinGW-w64 GCC 或 LLVM Clang，并确保 `gcc`/`clang` 在 `PATH` 中；也可以设置 `VISION_CC` 指向编译器可执行文件。

## 功能

- 选择固件 `project/code/vision` 源码目录。
- 加载标定工具导出的 PNG、RAW 或 PGM 帧。
- 使用 PC 硬件适配层编译并运行真实 C 视觉代码。
- 调整 Roll、Pitch、高度，查看二值图、连通域和信标框选结果。
- 可选输入“小车相对机体 Yaw”方向先验，复现固件双摄/通信链路对车标开口方向的软评分；关闭时保持纯视觉识别。
- “车标评分调参”页提供 18 个滑块，可实时覆盖臂长、对称性、开口比、凹陷分段、综合分门限、方向先验及五项权重；拖动停止约 220ms 后自动重跑当前帧，“恢复固件默认值”会回到源码宏配置。基础几何四项权重允许独立实验，界面会提示其总和应保持为 `1.00`。
- 结果 JSON 输出新版车标的臂对称性、开口比例、凸包凹陷、综合几何分和方向先验评分。
- 打开“连通域候选区”时会自动按当前管线逐候选重跑首轮、回退和正式路径，显示固件返回的子分、权重、动态 Blob 门槛及 Open-V 诊断。
- 上位机可调整精筛阈值及中心到边缘的五圈粗筛阈值（1~255），并单独输出去畸变/逆透视二值图。
- “处理与结果”和“车标评分调参”页支持右侧滚动条及鼠标滚轮，缩小窗口后仍可访问全部参数。
- 顶部“📌 置顶”按钮可将主窗口及已打开的候选区、图像调整和区域提取窗口固定在其他桌面窗口之前；候选区域同时是不会沉到主界面后方的非模态从属窗口，并提供独立“📌 置顶”按钮，可单独锁定在桌面最前方。
- 原图和二值图使用独立自适应展示框：滚轮缩放、左键拖拽平移、双击恢复适应大小；图片始终裁切在框内，中间区域变窄时自动由左右并排切换为上下排列。
- 去畸变输出为 `376x240`：保持标定焦距对应的原像素尺度，以主点为中心限制极端鱼眼边缘，并生成 `undistorted_mask.pgm` 有效区域掩码。
- 所有逆透视模式使用以正下方为中心的固定 `10m×10m` 画布；`0.5cm/pixel` 对应恒定 `2000x2000`，并生成 `birdview_mask.pgm`。
- 处理顺序可以选择灰度处理、先二值化再变换、先变换再二值化。
- 先二值化模式使用二值源图和最近邻采样；先变换模式使用灰度图双线性采样，完成几何变换后再按阈值二值化。
- 在左侧编辑并保存 C/H 文件，下一次构建或运行会使用最新源码。
- 构建日志、运行结果和中间二值图保存在 `runs/`。
- “提取单张区域”可在原图中框选目标，保持 `188×120` 画布不变并将框外填黑；RAW、PNG和保留原元数据的JSON保存到 `capture/区域提取/`。

## 自检

```powershell
python vision_tool.py --self-test
```

## 信标姿态自适应拟合

使用 `capture/分类` 下带姿态和 ToF 高度元数据的样本重新拟合轻量补偿系数：

```powershell
python fit_beacon_adaptive_thresholds.py
```

拟合报告写入 `runs/beacon_adaptive_fit/fit_report.json`。固件仅按候选中心、Roll、Pitch 和高度调整面积及形状门限，不生成信标逆透视图。

仿真适配层位于 `sim/`，不改写固件工程中的硬件头文件。当前工具不会自动覆盖固件文件，源码保存操作只写入你在 UI 中选择的源码目录。
