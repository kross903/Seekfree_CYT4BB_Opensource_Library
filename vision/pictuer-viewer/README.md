# MT9V03 图像特征查看器

独立离线工具，用于查看 `vision/capture` 中保存的图像并分析灰度和二值连通域。该工具不连接串口、不运行固件仿真，也不修改原始图片。

## 启动

在仓库根目录执行：

```powershell
python vision/pictuer-viewer/pictuer_viewer.py
```

依赖与现有视觉上位机相同，只需要 Pillow 和 Python 自带的 Tkinter：

```powershell
python -m pip install -r vision/requirements.txt
```

## 功能

- 递归浏览 `vision/capture`，PNG/RAW 同名时优先显示 PNG。
- 原始 `188x120` 灰度图和去畸变 `376x240` 灰度图切换。
- 去畸变直接读取固件的 `camera_calibration_params.h`，使用同一 fisheye 模型和双线性采样。
- 鼠标滚轮局部放大，右键拖动画面，悬停查看坐标、灰度和二值结果。
- 单一固定阈值实时二值化，规则为 `灰度值 >= 阈值`。
- 连续前景段连通域分析，默认使用与固件一致的 8 邻域。
- 输出面积、质心、外接框、边界像素、圆度和占空比。
- 双击候选或点击“打开候选”，独立查看候选灰度图和二值图。
- 自动读取同名 JSON 中的 Roll、Pitch、Yaw 和 ToF 高度。
- 在去畸变灰度图或单阈值二值图上叠加可拖动的理想箭头、理想信标。
- 理想箭头按物理端点投影并连成 V 形，不生成逐像素模板。
- 理想信标按水平圆形发光面投影，默认直径 `10 cm`，直径和离地高度可调。
- 小车 Yaw 优先读取同名 JSON；缺失时使用面板中的手动输入值。
- 相机安装 Roll、Pitch、Yaw 在上位机独立调整，三个角默认均为 `0°`。
- 在理想轮廓外接矩形内显示正形、负形离散采样点及实时灰度均值。
- 使用当前单阈值连通域的质心，将理想目标单点对齐到所选候选。
- 实时计算正负形分离度、命中率、固定阈值一致率和形状完整度。
- 通过独立弹窗调整箭头与信标的识别门槛，并显示未通过的具体原因。

工具会在退出时将目录、阈值、最小面积、邻域和理想目标参数保存到本目录的
`viewer_settings.json`。

## 理想目标

在右侧“理想目标投影”中选择“理想箭头”或“理想信标”。选择背景后，主画面会切换到
对应的 `376x240` 去畸变灰度图或单阈值二值图。

- 左键点击或拖动：移动当前理想目标中心。
- 右键拖动：平移画面。
- 鼠标滚轮：以鼠标位置为中心缩放。
- “重读JSON”：重新读取当前图片的同名遥测文件。
- “安装外参 R/P/Y”：实时调整相机相对机体的三个旋转角。
- “归零”：将三个相机安装角恢复为 `0°/0°/0°`。
- “对齐候选质心”：将当前理想目标中心移动到所选固定阈值连通域质心。
- “采样参数”：调整采样步长、采样框余量、正形轮廓带和负形最小距离。
- “识别阈值”：打开独立弹窗，分别调整箭头和信标的试判门槛。

正负形采样使用全图对齐的固定像素网格，默认步长为 `2 px`。理想轮廓外接框默认
向外扩展 `4 px`；距轮廓不超过 `1.5 px` 的点属于正形，距离在 `1.5~3 px`
之间的点忽略，距离不少于 `3 px` 的外部点属于负形。信标投影圆内部全部属于正形；
箭头是开放 V 形，因此远离两条箭头臂的框内点属于负形。

正形和负形灰度均值始终读取 `376x240` 去畸变灰度图。即使画面显示单阈值二值图，
灰度统计也不是二值化后的 `0/255`。工具会对当前理想目标进行独立试判，
不会修改原有固件视觉算法。

## 识别指标

局部自适应分割值为 `Tlocal = (正形均值 + 负形均值) / 2`。正形命中率统计
正形点中不低于 `Tlocal` 的比例，负形命中率统计负形点中低于 `Tlocal`
的比例。固定阈值一致率使用主界面二值阈值，取正形前景命中率和负形背景命中率的平均值。

标准化分离度为：

```text
(正形均值 - 负形均值) / sqrt((正形方差 + 负形方差) / 2 + 1)
```

箭头完整度取左右两臂命中率的较小值；信标完整度取四个图像象限命中率的较小值。
负形点还会按与理想轮廓的距离分为近负形环和远背景，两组灰度和对比度分开显示。

默认初值由 `vision/capture/旧图像/2灯` 中的6帧箭头和12个信标候选粗略拟合，
目的是保留较高召回率，不是最终严格门槛。弹窗中每项门槛都可单独启用或停用；
远背景门槛因小目标可能没有足够远背景采样点，默认不参与试判。

绝对小车 Yaw 模式下，箭头相对方向为
`wrap(小车Yaw - 无人机Yaw)`；勾选“相对机Yaw”后，输入值直接作为相对方向。
箭头开口方向还会叠加“开口偏移”，默认值为 `180°`。

上位机的三个相机安装角不读取固件中的 `CAMERA_MOUNT_*_OFFSET_DEG` 宏，首次启动和
旧设置文件缺少对应字段时均使用 `0°`。三个角会保存到 `viewer_settings.json`。
相机平移外参不在界面开放，仍只读取标定头文件中的固定值。

理想目标投影、采样和识别指标代码分别位于 `ideal_projection.py`、`ideal_sampling.py`、
`ideal_matching.py`，不导入
`vision_tool.py`、不运行固件仿真，也不修改无人机视觉识别代码。
